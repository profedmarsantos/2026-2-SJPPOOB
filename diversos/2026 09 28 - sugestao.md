# Roteiro Didático: Urna Eletrônica em C# (POO Básica)

Este documento apresenta a estrutura conceitual e arquitetural para o desenvolvimento de um projeto de **Urna Eletrônica em C#**, voltado para o ensino e fixação dos conceitos fundamentais de **Programação Orientada a Objetos (POO)** — incluindo **Herança** — e **Manipulação de Arrays Estáticos**.

---

## 1. Objetivos Didáticos

* **Abstração:** Mapear elementos do mundo real (`Pessoa`, `Candidato`, `Eleitor`, `Urna`) em classes de código.
* **Herança:** Aplicar o conceito de reuso e especialização de código através de uma classe base (`Pessoa`).
* **Encapsulamento:** Proteger atributos sensíveis (como a contagem de votos) permitindo alteração apenas via métodos controlados.
* **Arrays Estáticos (`T[]`):** Compreender o funcionamento de vetores com tamanho fixo e alocação de memória contígua em C#, sem a dependência de coleções dinâmicas (`List<T>`).
* **Controle de Índices:** Utilizar variáveis contadoras (`totalCadastrados`) para gerenciar a capacidade lógica de um vetor.
* **Desacoplamento (UI / Regra de Negócio):** Separar a lógica do sistema da interface gráfica ou interação com o usuário.

---

## 2. Estrutura de Classes (Modelo de Domínio)

```
                  +-------------------+
                  |      Pessoa       |  (Classe Base)
                  +-------------------+
                  | # nome: string    |
                  | # cpf: string     |
                  +-------------------+
                            ▲
                            │ (Herança :)
              ┌─────────────┴─────────────┐
              │                           │
    +-------------------+       +-------------------+
    |     Candidato     |       |      Eleitor      |
    +-------------------+       +-------------------+
    | - numero: int     |       | - titulo: string  |
    | - partido: string |       | - jaVotou: bool   |
    | - votos: int      |       +-------------------+
    +-------------------+
    | +AdicionarVoto()  |
    +-------------------+
```

---

### A. Classe Base `Pessoa`
Representa as características genéricas de qualquer indivíduo no sistema.

* **Atributos (Protegidos/Privados):**
  * `nome` (`string`): Nome completo da pessoa.
  * `cpf` (`string`): Documento de identificação.
* **Objetivo Didático:** Evitar a duplicação de atributos comuns em classes filhas.

---

### B. Classe `Candidato` (Herda de `Pessoa`)
Especialização de `Pessoa` para representar um concorrente ao pleito eleitoral (*"Candidato É UMA Pessoa"*).

* **Atributos Herdados:** `nome`, `cpf`.
* **Atributos Próprios (Privados):**
  * `numero` (`int`): Número do candidato na urna (ex: 13, 22, 45).
  * `partido` (`string`): Sigla/Nome do partido.
  * `votos` (`int`): Quantidade de votos recebidos.
* **Métodos:**
  * `AdicionarVoto()`: Incrementa a contagem de votos em `+1`.
  * *Getters/Properties*: Acesso aos dados do candidato para exibição no display da urna.

---

### C. Classe `Eleitor` (Herda de `Pessoa` - *Opcional*)
Especialização de `Pessoa` para representar quem está votando.

* **Atributos Herdados:** `nome`, `cpf`.
* **Atributos Próprios (Privados):**
  * `tituloEleitoral` (`string`): Número do título de eleitor.
  * `jaVotou` (`bool`): Flag para impedir voto duplicado do mesmo eleitor.

---

### D. Classe `UrnaEletronica`
Responsável pelo gerenciamento do pleito, armazenamento dos candidatos em array e computação dos votos.

* **Atributos (Privados):**
  * `candidatos` (`Candidato[]`): Array estático para armazenamento dos candidatos cadastrados.
  * `totalCadastrados` (`int`): Apontador do próximo índice livre e totalizador de candidatos inseridos.
  * `votosBrancos` (`int`): Contador de votos em branco.
  * `votosNulos` (`int`): Contador de votos nulos.
* **Métodos:**
  * `CadastrarCandidato(Candidato c)`: Insere um novo candidato no índice `totalCadastrados` e incrementa o contador (com validação do limite do vetor).
  * `BuscarCandidato(int numero)`: Percorre o array via laço `for` de `0` até `totalCadastrados - 1` e retorna o objeto correspondente.
  * `RegistrarVoto(int numero)`: Localiza o candidato e incrementa seu voto. Se não localizado, computa voto nulo.
  * `RegistrarVotoBranco()`: Incrementa o contador de votos brancos.
  * `ApurarResultados()`: Exibe a listagem de candidatos com seus respectivos totais de votos, brancos e nulos.

## 3. Conceito Chave: Gerenciamento do Vetor Sem Redimensionamento

Em C#, vetores (`Array`) possuem **tamanho fixo na memória**. Para evitar a complexidade de cópia e redimensionamento manual (`Array.Resize`), adota-se a seguinte estratégia:

1. **Capacidade Padrão Superdimensionada:** O vetor é alocado no construtor da classe com capacidade suficiente para cobrir os testes da aula (ex: `new Candidato[100]`).
2. **Capacidade Lógica via `totalCadastrados`:** Embora existam 100 posições (`null`) reservadas na memória, as buscas e varreduras são delimitadas por `totalCadastrados`.

```
Exemplo na memória (após cadastrar 2 candidatos):

   [0]        [1]        [2]        [3]     ...    [99]
+----------+----------+----------+----------+---+----------+
| Candidato| Candidato|   null   |   null   |...|   null   |
+----------+----------+----------+----------+---+----------+
     ▲          ▲
     │          │
  Usado      Usado     <--- Ignorado nos laços 'for' --->

totalCadastrados = 2
```

## 4. Estrutura da Interface Gráfica (WinForms)

Para dar vida ao projeto mantendo a separação de responsabilidades, o formulário (`Form1.cs`) atua apenas como a **camada de visão (UI)**.

### Mapeamento dos Componentes do Teclado da Urna

```
+-----------------------------------------------------+
|                      DISPLAY                        |
|                                                     |
| [ Número Digitado ]     [ Nome / Partido / Foto ]   |
|                                                     |
+-----------------------------------------------------+
|   [ 1 ]   [ 2 ]   [ 3 ]                             |
|   [ 4 ]   [ 5 ]   [ 6 ]                             |
|   [ 7 ]   [ 8 ]   [ 9 ]                             |
|           [ 0 ]                                     |
|                                                     |
| [ BRANCO ]   [ CORRIGE ]   [ CONFIRMA ]             |
+-----------------------------------------------------+
```

### Lógica dos Eventos de Interface

* **Estado da Tela (Variáveis Locais do Form):**
  * `numeroDigitado` (`string`): Mantém a sequência de caracteres clicados.
  * `candidatoEncontrado` (`Candidato`): Mantém a referência do candidato localizado na busca.

* **Teclas Numéricas (0 a 9):**
  * Concatena o dígito na variável `numeroDigitado`.
  * Ao atingir o tamanho esperado do número do cargo, invoca `urna.BuscarCandidato(...)`.
  * Se localizado, exibe dados/foto no Display. Caso contrário, sinaliza "VOTO NULO".

* **Tecla CORRIGE (Laranja):**
  * Limpa a string `numeroDigitado`.
  * Esconde os painéis de informação e foto no Display.

* **Tecla BRANCO (Branca):**
  * Permite acionamento apenas com `numeroDigitado` vazio.
  * Seta a confirmação para voto em branco no Display.

* **Tecla CONFIRMA (Verde):**
  * Dispara a chamada correspondente na classe `UrnaEletronica` (`RegistrarVoto`, `RegistrarVotoBranco` ou `RegistrarVotoNulo`).
  * Emite feedback sonoro ("TU-TU-TU").
  * Exibe mensagem "FIM" por tempo determinado e limpa a tela para o próximo ciclo.

## 5. Sequência Recomendada para Ministrar a Aula

1. **Sessão 1 (Herança e Modelagem Básica):**
   * Criação da classe base `Pessoa` (Abstração e Atributos Comuns).
   * Criação da subclasse `Candidato` demonstrando o uso de Herança (`class Candidato : Pessoa`) e o repasse de parâmetros para o construtor base (`base`).
2. **Sessão 2 (Arrays e Gerenciamento de Memória):**
   * Criação da classe `UrnaEletronica`.
   * Manipulação do array fixo de `Candidato[]` e a lógica da variável apontadora `totalCadastrados`.
3. **Sessão 3 (Lógica de Controle e Busca):**
   * Escrita dos métodos de busca (`for`), cadastro e contagem/computação de votos.
4. **Sessão 4 (Integração com UI):**
   * Construção do layout no Windows Forms e vinculação dos botões aos métodos da classe `UrnaEletronica`.
