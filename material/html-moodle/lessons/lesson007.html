Aula 07 - Construtores

Objetivo: inicializar objetos com dados obrigatorios.

Conceitos desta aula

  • Construtor
  • Inicializacao

Definicoes

Construtor e executado no momento da criacao do objeto.

Explicacao curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

class Pessoa
{
    public string Nome;
    public int Idade;

    public Pessoa(string nome, int idade)
    {
        Nome = nome;
        Idade = idade;
    }
}

Resumo

Construtor melhora consistencia dos dados iniciais.

Atividade

Crie um construtor para Produto com nome e preco.
