Módulo 07

Construtores

Objetivo: inicializar objetos com dados obrigatórios no momento da criação.

Introdução teórica

Construtor é um método especial chamado automaticamente quando o objeto é criado.

Ele garante que o objeto já nasça em estado válido, com dados iniciais definidos.

Conceitos essenciais desta aula

  • Construtor: método com mesmo nome da classe e sem tipo de retorno.
  • Inicialização: atribuição de valores iniciais ao criar o objeto.
  • Sobrecarga: uso de mais de um construtor com assinaturas diferentes.

Exemplo em C#

Arquivo 1: Produto.cs

using System;

public class Produto
{
    public string Nome;
    public decimal Preco;

    public Produto(string nome, decimal preco)
    {
        Nome = nome;
        Preco = preco;
    }

    public Produto(string nome)
    {
        Nome = nome;
        Preco = 0m;
    }

    public void Exibir()
    {
        Console.WriteLine("Nome: " + Nome + " | Preco: " + Preco);
    }
}

Arquivo 2: Program.cs

using System;

class Program
{
    static void Main()
    {
        Produto p1 = new Produto("Teclado", 120m);
        Produto p2 = new Produto("Mouse");

        p1.Exibir();
        p2.Exibir();
    }
}

Leitura guiada do exemplo

  1. O primeiro construtor recebe nome e preço.
  2. O segundo construtor recebe apenas nome e define preço padrão.
  3. No Main, cada chamada de new Produto(...) escolhe automaticamente o construtor compatível.

Exercícios de fixação

  1. Exercício 1: crie a classe Aluno com construtor que receba nome e idade.

    Ver resposta 
    class Aluno
{
    public string Nome;
    public int Idade;

    public Aluno(string nome, int idade)
    {
        Nome = nome;
        Idade = idade;
    }
}

  2. Exercício 2: adicione sobrecarga para criar Aluno apenas com nome e idade padrão 0.

    Ver resposta 
    public Aluno(string nome)
{
    Nome = nome;
    Idade = 0;
}

  3. Exercício 3: explique por que construtor ajuda a evitar objeto incompleto.

    Ver resposta

    Porque ele força a inicialização no momento da criação, reduzindo chance de atributos importantes ficarem sem valor adequado.

  4. Exercício 4: crie um programa que instancie dois objetos da mesma classe usando construtores diferentes.

    Ver resposta

    Use uma instância com todos os parâmetros e outra com sobrecarga para comparar os estados iniciais.

Resumo da aula

Construtor define o estado inicial do objeto de forma controlada.

Sobrecarga de construtores oferece flexibilidade sem perder consistência.

Atividade guiada

Passo 1: crie a classe ContaAluno com atributos Nome e Saldo.

Passo 2: implemente um construtor com os dois parâmetros.

Passo 3: implemente uma sobrecarga com apenas nome e saldo inicial igual a zero.

Passo 4: crie objetos usando os dois construtores e exiba os dados.
