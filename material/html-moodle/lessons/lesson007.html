Módulo 07

Construtores

Objetivo: inicializar objetos com dados obrigatórios no momento da criação.

1. Introdução teórica

Construtor é um método especial chamado automaticamente quando o objeto é criado.

Ele garante que o objeto já nasça em estado válido, com dados iniciais definidos.

2. Conceitos essenciais desta aula

  • Construtor: método com mesmo nome da classe e sem tipo de retorno.
  • Inicialização: atribuição de valores iniciais ao criar o objeto.
  • Sobrecarga: uso de mais de um construtor com assinaturas diferentes.

3. Exemplo em C#

Arquivo 1: Produto.cs

using System;

public class Produto
{
    public string Nome;
    public decimal Preco;

    public Produto(string nome, decimal preco)
    {
        Nome = nome;
        Preco = preco;
    }

    public Produto(string nome)
    {
        Nome = nome;
        Preco = 0m;
    }

    public void Exibir()
    {
        Console.WriteLine("Nome: " + Nome + " | Preco: " + Preco);
    }
}

Arquivo 2: Program.cs

using System;

class Program
{
    static void Main()
    {
        Produto p1 = new Produto("Teclado", 120m);
        Produto p2 = new Produto("Mouse");

        p1.Exibir();
        p2.Exibir();
    }
}

4. Leitura guiada do exemplo

  1. O primeiro construtor recebe nome e preço.
  2. O segundo construtor recebe apenas nome e define preço padrão.
  3. No Main, cada chamada de new Produto(...) escolhe automaticamente o construtor compatível.

6. Exercícios integradores

Os exercícios a seguir revisam classes, objetos, atributos, métodos, construtores e encapsulamento.

  1. 6.1 Exercício: Produto

    Objetivo

    Criar a classe Produto para representar um item em estoque, aplicando encapsulamento, construtor e método.

    Diagrama de Classe

    classDiagram class Produto { -nome: string -preco: double +Produto(nome: string, preco: double) +Nome: string +Preco: double +ExibirInformacoes() void } class Program { ~Main() void$ } Program ..> Produto : cria e usa

    Conhecimentos necessários

    • Conceito de classe e objeto.
    • Declaração de atributos e métodos.
    • Uso de construtores para inicialização.
    • Aplicação de encapsulamento com modificadores de acesso e propriedades.

    Conceitos principais

    Integrar os conceitos vistos para modelar uma entidade com dados protegidos e comportamentos definidos.

    Definições

    • Classe: modelo que define a estrutura e o comportamento de objetos.
    • Objeto: instância de uma classe.
    • Encapsulamento: proteção dos dados internos por meio de propriedades públicas e atributos privados.
    • Construtor: método especial executado no momento da criação do objeto.

    Explicação

    Você deve definir a visibilidade correta dos dados, inicializá-los com um construtor e criar um método para exibir as informações.

    Regras

    1. Crie os atributos privados nome (string) e preco (double).
    2. Crie um construtor que receba o nome e o preço.
    3. Crie propriedades públicas. Se o preço for menor que zero, defina-o como zero.
    4. Crie o método ExibirInformacoes.
    5. No Main, crie um objeto, altere o preço e exiba os dados finais.

    Dados de entrada (exemplo)

    Nome: Caderno
    Preço inicial: 25,50

    Processamento esperado

    • O construtor atribui os valores iniciais.
    • A propriedade valida se o preço é maior ou igual a zero.
    • O método exibe os dados formatados.

    Resultado esperado

    Produto: Caderno
Preço: R$ 25,50
    Ver solução em C#

    Arquivo 1: Produto.cs

    using System;

class Produto
{
    private string nome;
    private double preco;

    public Produto(string nome, double preco)
    {
        this.nome = nome;
        Preco = preco;
    }

    public string Nome
    {
        get { return nome; }
        set { nome = value; }
    }

    public double Preco
    {
        get { return preco; }
        set
        {
            if (value >= 0)
                preco = value;
            else
                preco = 0;
        }
    }

    public void ExibirInformacoes()
    {
        Console.WriteLine("Produto: " + nome);
        Console.WriteLine("Preço: R$ " + preco);
    }
    }

    Arquivo 2: Program.cs

    using System;

    class Program
    {
      static void Main()
      {
        Produto meuProduto = new Produto("Caderno", 25.50);
        meuProduto.ExibirInformacoes();
      }
    }

    Explicação da solução

    • Atributos privados: protegem nome e preco contra acesso direto.
    • Construtor: recebe os dados iniciais do objeto.
    • Propriedades: controlam o acesso e validam o preço.
    • Método: centraliza a exibição das informações.

    Erros comuns

    • Acessar diretamente meuProduto.preco fora da classe.
    • Esquecer a validação do preço negativo.
    • Declarar o construtor com nome diferente do nome da classe.

    Resumo

    Classes agrupam dados e comportamentos. O encapsulamento protege os atributos. O construtor inicializa o objeto.

  2. 6.2 Exercício: ContaBancaria

    Objetivo

    Criar a classe ContaBancaria para representar uma conta com saldo protegido.

    Diagrama de Classe

    classDiagram class ContaBancaria { -titular: string -saldo: double +ContaBancaria(titular: string, saldo: double) +Titular: string +Saldo: double +ExibirSaldo() void } class Program { ~Main() void$ } Program ..> ContaBancaria : cria e usa

    Conhecimentos necessários

    • Conceito de classe e objeto.
    • Modificadores de acesso private e public.
    • Uso de construtores para inicialização.
    • Uso de propriedades com blocos get e set.

    Conceitos principais

    Usar construtores para inicializar objetos e propriedades para proteger dados internos.

    Definições

    • Encapsulamento: proteção de dados privados por meio de propriedades públicas.
    • Construtor: método chamado automaticamente na criação de um objeto.

    Explicação

    Use um construtor para receber os valores iniciais e propriedades com lógica para impedir dados inválidos.

    Regras

    1. Crie os atributos privados titular (string) e saldo (double).
    2. Crie um construtor que receba o titular e o saldo inicial.
    3. Crie a propriedade Saldo. Valores negativos não podem alterar o saldo.
    4. Crie a propriedade Titular.
    5. Crie o método ExibirSaldo e teste um valor negativo no Main.

    Dados de entrada (exemplo)

    Titular: Ana
    Saldo inicial: 100,00

    Processamento esperado

    • O construtor atribui o titular e o saldo inicial.
    • A propriedade impede a alteração para um saldo negativo.
    • O método exibe os dados da conta.

    Resultado esperado

    Titular: Ana
Saldo: R$ 100,00
    Ver solução em C#

    Arquivo 1: ContaBancaria.cs

    using System;

class ContaBancaria
{
    private string titular;
    private double saldo;

    public ContaBancaria(string titular, double saldo)
    {
        this.titular = titular;
        Saldo = saldo;
    }

    public string Titular
    {
        get { return titular; }
        set { titular = value; }
    }

    public double Saldo
    {
        get { return saldo; }
        set
        {
            if (value >= 0)
                saldo = value;
        }
    }

    public void ExibirSaldo()
    {
        Console.WriteLine("Titular: " + titular);
        Console.WriteLine("Saldo: R$ " + saldo);
    }
    }

    Arquivo 2: Program.cs

    using System;

    class Program
    {
      static void Main()
      {
        ContaBancaria minhaConta = new ContaBancaria("Ana", 100.00);
        minhaConta.Saldo = -50;
        minhaConta.ExibirSaldo();
      }
    }

    Explicação da solução

    • Atributos privados: protegem titular e saldo.
    • Construtor: inicializa o objeto no momento da criação.
    • Propriedade Saldo: impede valores negativos.
    • Método ExibirSaldo: mostra os dados formatados.

    Erros comuns

    • Acessar diretamente o atributo saldo fora da classe.
    • Esquecer this quando parâmetro e atributo têm o mesmo nome.
    • Permitir valores negativos no saldo.

    Resumo

    Construtores inicializam objetos com dados válidos. Propriedades controlam alterações nos dados privados.

  3. 6.3 Exercício: ProdutoLoja

    Objetivo

    Criar a classe ProdutoLoja para representar um item com controle de quantidade em estoque.

    Diagrama de Classe

    classDiagram class ProdutoLoja { -nome: string -quantidade: int +ProdutoLoja(nome: string, quantidade: int) +Nome: string +Quantidade: int +ExibirEstoque() void } class Program { ~Main() void$ } Program ..> ProdutoLoja : cria e usa

    Conhecimentos necessários

    • Modificadores de acesso private e public.
    • Uso de propriedades com blocos get e set.
    • Uso de construtores para inicialização.

    Conceitos principais

    Impedir a alteração direta de dados privados e aplicar restrições por meio de propriedades.

    Definições

    • Encapsulamento: proteção dos dados internos da classe.
    • Validação: regra aplicada para aceitar ou recusar novos valores.

    Explicação

    Use propriedades para verificar se os valores atendem às regras antes de alterar os atributos privados.

    Regras

    1. Crie os atributos privados nome (string) e quantidade (int).
    2. Crie um construtor que receba o nome e a quantidade inicial.
    3. Crie a propriedade Quantidade. Se o valor for negativo, mantenha a quantidade atual.
    4. Crie a propriedade Nome.
    5. Crie o método ExibirEstoque e teste a validação no Main.

    Dados de entrada (exemplo)

    Nome: Teclado
    Quantidade inicial: 15

    Processamento esperado

    • O construtor atribui os valores iniciais.
    • A propriedade aceita somente quantidade maior ou igual a zero.
    • O método exibe o estado atual do estoque.

    Resultado esperado

    Produto: Teclado
Quantidade: 15
    Ver solução em C#

    Arquivo 1: ProdutoLoja.cs

    using System;

class ProdutoLoja
{
    private string nome;
    private int quantidade;

    public ProdutoLoja(string nome, int quantidade)
    {
        this.nome = nome;
        Quantidade = quantidade;
    }

    public string Nome
    {
        get { return nome; }
        set { nome = value; }
    }

    public int Quantidade
    {
        get { return quantidade; }
        set
        {
            if (value >= 0)
                quantidade = value;
        }
    }

    public void ExibirEstoque()
    {
        Console.WriteLine("Produto: " + nome);
        Console.WriteLine("Quantidade: " + quantidade);
    }
    }

    Arquivo 2: Program.cs

    using System;

    class Program
    {
      static void Main()
      {
        ProdutoLoja meuProduto = new ProdutoLoja("Teclado", 15);
        meuProduto.Quantidade = -2;
        meuProduto.ExibirEstoque();
      }
    }

    Explicação da solução

    • Atributos privados: protegem o nome e a quantidade.
    • Construtor: inicializa os dados obrigatórios.
    • Propriedade Quantidade: valida o valor antes de atualizar o atributo.
    • Método ExibirEstoque: mostra os valores atuais.

    Erros comuns

    • Modificar diretamente o atributo quantidade.
    • Esquecer a validação de valores menores que zero.

    Resumo

    Propriedades com validação protegem o estado interno. O construtor garante que o objeto comece com dados consistentes.

7. Resumo da aula

Construtor define o estado inicial do objeto de forma controlada.

Sobrecarga de construtores oferece flexibilidade sem perder consistência.
