Aula 05 - Metodos

Objetivo: organizar acoes e calculos com metodos.

Conceitos desta aula

  • Metodo
  • Parametro
  • Retorno

Definicoes

Metodo e uma acao da classe. Parametro e o dado recebido. Retorno e o resultado devolvido.

Explicacao curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

class Calculadora
{
    public int Somar(int a, int b)
    {
        return a + b;
    }
}

Resumo

Metodos evitam repeticao e organizam regras de negocio.

Atividade

Crie um metodo Media que receba duas notas.
