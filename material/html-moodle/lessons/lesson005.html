Módulo 05 - Métodos

Objetivo: Organizar Ações e Calculos com Métodos.

Conceitos Desta Aula

  • método
  • Parametro
  • Retorno

Definições

método e uma ação da classe. Parametro e o dado recebido. Retorno e o resultado devolvido.

Explicação Curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo Curto

class Calculadora
{
    public int Somar(int a, int b)
    {
        return a + b;
    }
}

Resumo

métodos evitam repetição e organizam regras de negocio.

Atividade

Crie um método Media que receba duas notas.
