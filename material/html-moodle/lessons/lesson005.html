Módulo 05

Métodos

Objetivo: organizar ações em métodos, usando parâmetros e retorno para evitar repetição de código.

Introdução teórica

Método é o bloco de código que executa uma tarefa específica da classe.

Com métodos, você separa responsabilidades, reutiliza regras e melhora a leitura do programa.

Conceitos essenciais desta aula

  • Método: ação definida dentro da classe.
  • Parâmetro: valor recebido pelo método para executar sua regra.
  • Retorno: resultado devolvido pelo método ao final da execução.

Exemplo em C#

using System;

class Calculadora
{
    public int Somar(int a, int b)
    {
        return a + b;
    }

    public double CalcularMedia(double n1, double n2)
    {
        return (n1 + n2) / 2;
    }
}

class Program
{
    static void Main()
    {
        Calculadora calc = new Calculadora();

        int total = calc.Somar(5, 7);
        double media = calc.CalcularMedia(8.0, 6.0);

        Console.WriteLine("Soma: " + total);
        Console.WriteLine("Média: " + media);
    }
}

Leitura guiada do exemplo

  1. Somar: recebe dois inteiros e devolve a soma.
  2. CalcularMedia: recebe duas notas e devolve um valor double.
  3. Main: cria o objeto e chama os métodos para obter resultados.
  4. Saída: os valores retornados são guardados em variáveis antes de exibir.

Erros comuns nesta etapa

  • Assinatura incorreta: declarar tipo de retorno diferente do valor retornado.
  • Ordem de parâmetros: trocar a ordem e gerar resultado errado.
  • Falta de retorno: esquecer return em método que não é void.

Exercícios de fixação

  1. Exercício 1: crie o método Multiplicar(int a, int b) e retorne o produto.

    Ver resposta 
    public int Multiplicar(int a, int b)
{
    return a * b;
}

  2. Exercício 2: crie o método MostrarMensagem(string texto) sem retorno.

    Ver resposta 
    public void MostrarMensagem(string texto)
{
    Console.WriteLine(texto);
}

  3. Exercício 3: explique a diferença entre método void e método com retorno.

    Ver resposta

    O método void executa uma ação sem devolver valor. O método com retorno devolve um resultado que pode ser armazenado em variável.

  4. Exercício 4: crie um método Maior(int a, int b) que devolva o maior valor.

    Ver resposta 
    public int Maior(int a, int b)
{
    if (a > b)
        return a;

    return b;
}

Resumo da aula

Métodos organizam ações da classe. Parâmetros permitem entrada de dados e retorno devolve resultados.

Esse padrão reduz repetição e melhora a manutenção do código.

Atividade guiada

Passo 1: crie a classe Boletim com método CalcularMedia(double n1, double n2, double n3).

Passo 2: crie método MostrarSituacao(double media) para exibir aprovado ou reprovado.

Passo 3: no Main, chame os dois métodos e teste com dois conjuntos de notas.
