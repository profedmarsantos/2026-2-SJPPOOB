Aula 03 - Classe e objeto

Objetivo: diferenciar classe de objeto e criar instancias.

Conceitos desta aula

  • Classe
  • Objeto
  • Instancia

Definições

Classe e o tipo. Objeto e uma instancia desse tipo.

Explicação curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

class Livro
{
    public string Titulo;
    public string Autor;
}

Livro l1 = new Livro();
l1.Titulo = "Algoritmos";

Resumo

Classe e definicao. Objeto e uso concreto da definicao.

Atividade

Crie dois objetos da classe Livro com valores diferentes.
