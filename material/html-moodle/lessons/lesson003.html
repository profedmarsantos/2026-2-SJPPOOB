Módulo 03

Classe e Objeto

Objetivo: compreender a relação entre classe e objeto e aplicar atributos e métodos em instâncias diferentes.

Classe e objeto na prática

A classe define o modelo. O objeto é a instância criada a partir desse modelo.

Cada objeto guarda seus próprios dados e executa ações por meio de métodos.

Conceitos essenciais desta aula

Atributo

Armazena informações do objeto, como nome, idade, saldo ou preço.

Método

Representa uma ação que o objeto pode executar, como mostrar dados ou calcular um valor.

Estado

É o conjunto de valores atuais armazenados nos atributos do objeto.

Comportamento

É a forma como o objeto reage quando um método é chamado.

Resumo: a classe define o modelo; os atributos guardam os dados; os métodos representam as ações; cada objeto possui seu próprio estado.

Exemplo com atributo e método

Vamos construir uma classe Conta com um saldo e um método para depositar dinheiro.

using System;

class Conta
{
    public string Titular;
    public double Saldo;

    public void Depositar(double valor)
    {
        Saldo = Saldo + valor;
    }

    public void ExibirSaldo()
    {
        Console.WriteLine("Saldo atual: " + Saldo);
    }
}

class Program
{
    static void Main()
    {
        Conta c1 = new Conta();
        c1.Titular = "Ana";
        c1.Saldo = 100;
        c1.Depositar(50);
        c1.ExibirSaldo();
    }
}

Neste exemplo, o objeto c1 tem seus próprios dados e pode executar ações por meio dos métodos.

Leitura guiada do exemplo

  1. Classe Conta: define os atributos Titular e Saldo.
  2. Método Depositar: recebe um valor e soma no saldo atual.
  3. Método ExibirSaldo: mostra no console o estado atual do objeto.
  4. Objeto c1: é criado com new Conta() e recebe valores próprios.
  5. Chamada de método: ao executar Depositar(50), o estado do objeto muda de 100 para 150.

Esse fluxo mostra a ideia central da aula: a classe define o modelo e o objeto guarda o estado real durante a execução.

Diferença entre atributo e método

O atributo guarda informação. O método executa uma ação.

Em uma classe Aluno, o atributo Nome guarda o nome do aluno. O método Apresentar mostra esse nome na tela.

Assim, a classe une dados e comportamento em um único modelo.

Vários objetos, valores diferentes

Cada objeto pode ter valores diferentes para os mesmos atributos. Isso é um ponto importante da POO.

Conta c1 = new Conta();
Conta c2 = new Conta();

c1.Titular = "Ana";
c1.Saldo = 100;

c2.Titular = "Bruno";
c2.Saldo = 300;

Mesmo usando a mesma classe, os objetos c1 e c2 possuem estados diferentes.

Erros comuns nesta etapa

  • Esquecer de criar o objeto: tentar usar atributos e métodos sem executar new.
  • Confundir classe com objeto: tratar o nome da classe como se já fosse uma instância.
  • Não alterar o estado: chamar método sem atualizar os dados necessários.
  • Duplicar lógica no Main: colocar regras de negócio fora da classe em vez de usar métodos.

Resumo da Aula

A classe organiza dados e ações. Os atributos guardam o estado do objeto, enquanto os métodos definem o comportamento.

Isso torna o código mais claro, mais organizado e mais próximo de situações reais.

Passo 1: crie a classe Produto com os atributos Nome e Quantidade.

Passo 2: crie o método Exibir() para mostrar os dados de um produto.

Passo 3: no Main, crie dois objetos com valores diferentes.

Passo 4: chame Exibir() para cada objeto e compare os estados.
