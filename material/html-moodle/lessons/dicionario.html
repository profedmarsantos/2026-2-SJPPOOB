Material de apoio

Dicionário do Projeto

Consulte os conceitos de programação, orientação a objetos, banco de dados e distribuição estudados nos 20 módulos.

Conceitos em ordem alfabética

  1. Abstração:

    Foca nas características essenciais de um problema e deixa de lado detalhes que não são necessários naquele momento.

  2. abstract (código):

    Palavra-chave que declara uma classe ou método abstrato. Uma classe abstrata não pode ser criada diretamente e um método abstrato deve ser implementado por uma classe derivada.

  3. Acesso a banco de dados:

    Processo de conectar o programa ao banco para enviar comandos e receber dados.

  4. Acoplamento:

    Grau de dependência entre classes ou partes do sistema. Acoplamento baixo facilita alterações sem causar efeitos desnecessários em outras partes.

  5. Atributo:

    Dado armazenado em um objeto, como nome, preço, idade ou saldo.

  6. Banco de dados:

    Conjunto organizado de dados que pode manter informações mesmo depois que o programa é fechado.

  7. base (código):

    Palavra-chave usada em uma classe derivada para acessar membros, construtores ou métodos da classe base.

  8. Build:

    Processo de compilação do código para gerar os arquivos necessários à execução do programa.

  9. Campo:

    Coluna de uma tabela do banco de dados, com um nome e um tipo de dado definido.

  10. Chave primária:

    Campo que identifica cada registro de forma única dentro de uma tabela.

  11. class (código):

    Palavra-chave usada para declarar uma classe em C#.

  12. Classe abstrata:

    Classe usada como base para outras classes e que não pode ser instanciada diretamente.

  13. Classe base:

    Classe que fornece membros comuns para serem reutilizados por classes derivadas.

  14. Classe derivada:

    Classe que herda membros de uma classe base e pode acrescentar seus próprios membros.

  15. Classe:

    Modelo que define os dados e os comportamentos que os objetos daquele tipo poderão ter.

  16. Coleção:

    Estrutura que armazena vários elementos e permite trabalhar com eles de forma organizada.

  17. Comando SQL:

    Instrução escrita em SQL para consultar ou alterar dados no banco.

  18. Construtor:

    Método especial com o mesmo nome da classe, executado automaticamente na criação de um objeto.

  19. Consulta:

    Comando, normalmente um SELECT, usado para recuperar os dados necessários.

  20. CREATE (código):

    Operação do CRUD usada para criar um novo registro, normalmente com o comando SQL INSERT.

  21. CRUD:

    Conjunto das operações básicas de dados: criar, consultar, atualizar e excluir.

  22. Dado privado:

    Informação que só pode ser acessada diretamente dentro da classe que a declarou.

  23. DELETE (código):

    Operação do CRUD usada para excluir um registro existente.

  24. Dependência:

    Arquivo, biblioteca ou recurso necessário para o programa funcionar.

  25. Encapsulamento:

    Prática de proteger os dados internos e permitir alterações por operações controladas.

  26. Entidade:

    Elemento do problema real que será representado no sistema por uma classe e seus objetos.

  27. Estado:

    Conjunto dos valores atuais armazenados nos atributos de um objeto.

  28. Filtro:

    Condição que limita os registros exibidos por uma consulta ou relatório.

  29. Fluxo completo:

    Sequência integrada de modelar classes, aplicar regras, persistir dados, gerar relatórios e publicar a aplicação.

  30. get (código):

    Parte de uma propriedade usada para devolver o valor atual.

  31. Herança:

    Recurso que permite criar uma classe a partir de outra, reutilizando seus membros.

  32. Implementação:

    Código escrito para cumprir um contrato, como os métodos exigidos por uma interface.

  33. Inicialização:

    Atribuição dos valores iniciais de um objeto durante ou depois de sua criação.

  34. INSERT (código):

    Comando SQL usado para inserir um novo registro em uma tabela.

  35. Instância:

    Objeto específico criado a partir de uma classe.

  36. interface (código):

    Palavra-chave usada para declarar um contrato de membros que uma classe deve implementar.

  37. Interface:

    Contrato que define operações obrigatórias sem fornecer, em regra, a implementação concreta delas.

  38. internal (código):

    Modificador de acesso que permite o uso de um membro dentro do mesmo assembly, normalmente o mesmo projeto compilado.

  39. Iteração:

    Repetição do processamento dos elementos de uma coleção, usando recursos como for ou foreach.

  40. Layout:

    Organização visual de um relatório, incluindo cabeçalho, colunas e totalizadores.

  41. List<T> (código):

    Coleção genérica do C# que armazena vários valores ou objetos do tipo T.

  42. Método abstrato:

    Método declarado sem corpo que deve ser implementado pelas classes derivadas.

  43. Método:

    Bloco de código que define uma ação ou operação de uma classe.

  44. Modificador de acesso:

    Palavra-chave que define onde uma classe ou membro pode ser usado, como public, private e protected.

  45. new (código):

    Palavra-chave usada para criar uma instância de uma classe.

  46. Objeto:

    Instância concreta de uma classe, com seus próprios valores e comportamentos disponíveis.

  47. Ordenação:

    Definição da sequência em que os dados serão apresentados, por exemplo, em ordem alfabética.

  48. Parâmetro:

    Valor recebido por um método para que ele execute sua operação.

  49. Polimorfismo:

    Recurso que permite tratar objetos diferentes por uma referência comum, mantendo comportamentos específicos.

  50. private (código):

    Modificador de acesso que permite o uso direto de um membro somente dentro da própria classe.

  51. Propriedade:

    Membro que oferece leitura ou escrita controlada de um valor, normalmente por get e set.

  52. protected (código):

    Modificador de acesso que permite o uso de um membro na própria classe e nas classes derivadas.

  53. public (código):

    Modificador de acesso que permite o uso de um membro por outras partes autorizadas do programa.

  54. Publish:

    Processo de gerar o pacote de arquivos preparado para distribuir e executar a aplicação.

  55. READ (código):

    Operação do CRUD usada para consultar registros, normalmente com o comando SQL SELECT.

  56. Registro:

    Linha de uma tabela que representa um item cadastrado.

  57. Release:

    Configuração otimizada do projeto usada para gerar a versão destinada à entrega.

  58. Retorno:

    Resultado que um método devolve ao terminar sua execução.

  59. Reuso:

    Utilização de um código já criado em mais de um ponto, reduzindo repetição.

  60. sealed (código):

    Palavra-chave que impede novas classes de herdarem de uma classe ou sobrescreverem um método marcado dessa forma.

  61. SELECT (código):

    Comando SQL usado para consultar e recuperar dados de uma ou mais tabelas.

  62. set (código):

    Parte de uma propriedade usada para receber e, quando necessário, validar um novo valor.

  63. Sintaxe:

    Conjunto de regras que define a forma correta de escrever comandos em uma linguagem.

  64. Sobrecarga:

    Criação de métodos ou construtores com o mesmo nome e parâmetros diferentes.

  65. Sobrescrita:

    Redefinição, em uma classe derivada, do comportamento herdado de um método.

  66. SqlCommand (código):

    Objeto usado em C# para enviar e executar um comando SQL.

  67. SqlConnection (código):

    Objeto usado em C# para abrir e fechar a conexão com um banco de dados.

  68. Tabela:

    Estrutura do banco de dados que organiza registros sobre um tema ou entidade.

  69. Tipo de dado:

    Regra que define quais valores podem ser armazenados, como int, string ou decimal.

  70. UPDATE (código):

    Operação do CRUD usada para alterar dados existentes em um registro.

  71. using (código):

    Recurso que libera automaticamente um recurso, como uma conexão ou comando, ao fim do bloco.

  72. Validação:

    Regra que verifica se um valor ou operação atende às condições permitidas.

  73. virtual (código):

    Palavra-chave que permite que um método seja sobrescrito em uma classe derivada.

  74. void (código):

    Tipo de retorno usado quando um método executa uma ação, mas não devolve um valor.
