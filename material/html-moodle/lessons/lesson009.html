Aula 09 - Modificadores de acesso

Objetivo: usar public, private e protected corretamente.

Conceitos desta aula

  • public
  • private
  • protected

Definicoes

public libera acesso geral. private restringe a propria classe. protected libera para classes derivadas.

Explicacao curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

class Pessoa
{
    public string Nome;
    private string cpf;
    protected string CodigoInterno;
}

Resumo

Nivel de acesso faz parte da modelagem correta de classes.

Atividade

Classifique os atributos de Conta em publicos e privados.
