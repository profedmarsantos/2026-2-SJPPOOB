Aula 01 - Transição de C para C#

Objetivo: compreender como reaproveitar a mesma lógica aprendida em C, mudando a sintaxe e a organização do código para C#.

Por que esta Transição e importante

Você não está recomeçando do zero. O que já aprendeu em C continua valendo: leitura de dados, cálculos, estruturas de decisão, repetição e organização em funções.

O que muda é a forma de escrever. Em C#, o código fica mais organizado em tipos e métodos, com bibliotecas padrão que facilitam tarefas comuns.

A regra principal desta aula e simples: a lógica permanece, a sintaxe muda.

Conceitos centrais

lógica Sintaxe Entrada e Saída Conversão de tipos Estruturas de controle

lógica é a sequência de passos para resolver um problema.

Sintaxe é o jeito correto de escrever esses passos em cada linguagem.

Conversão de tipos em C# aparece quando você lê texto com Console.ReadLine() e transforma em número.

Entrada de dados: o que muda na pratica

Em C, scanf ja coloca o valor no tipo certo quando a mascara esta correta. Em C#, Console.ReadLine() sempre devolve texto. Por isso, voce converte o valor manualmente.

Exemplo em C

#include <stdio.h>

int main() {
    int idade;

    printf("Digite sua idade: ");
    scanf("%d", &idade);

    printf("Idade informada: %d\n", idade);
    return 0;
}

Exemplo equivalente em C#

using System;

class Program
{
    static void Main()
    {
        Console.Write("Digite sua idade: ");
        int idade = int.Parse(Console.ReadLine());

        Console.WriteLine("Idade informada: " + idade);
    }
}

Repare na equivalencia:

  • printf vira Console.Write/WriteLine.
  • scanf vira Console.ReadLine + int.Parse.
  • A variavel continua sendo int, com o mesmo significado matematico.

Decisão e repetição: a lógica continua igual

Quando você aprendeu if, for e while em C, já aprendeu o raciocínio principal. Em C#, você usa os mesmos blocos de decisão e repetição.

using System;

class Program
{
    static void Main()
    {
        for (int i = 1; i <= 5; i++)
        {
            if (i % 2 == 0)
            {
                Console.WriteLine(i + " e par");
            }
            else
            {
                Console.WriteLine(i + " e impar");
            }
        }
    }
}

O código acima usa a mesma ideia que voce ja praticou: percorrer valores e classificar cada um por uma condicao.

Erros comuns de quem esta migrando

  1. Esquecer que ReadLine retorna texto.
  2. Tentar usar scanf em C#.
  3. Confundir Write com WriteLine.
  4. não validar entrada quando o usuario pode digitar valor invalido.

Com pratica, esses pontos viram rotina. O mais importante e manter o foco na sequencia lógica da solucao.

Resumo da aula

A Transição de C para C# não exige abandonar o que voce sabe. Voce aproveita a base de lógica e aprende uma nova forma de expressar essa base.

Ao final desta etapa, voce deve conseguir:

  • Escrever entrada e saida em C#.
  • Converter texto para numeros.
  • Reproduzir em C# algoritmos simples que ja funcionavam em C.

Atividade

Escolha um exercicio em C que voce ja resolveu e reescreva em C# mantendo a mesma lógica. Depois, anote em duas colunas:

  • Comandos usados em C.
  • Comandos equivalentes em C#.
