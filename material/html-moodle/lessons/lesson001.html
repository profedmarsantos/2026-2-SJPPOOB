Aula 01 - Transição de C para C#

Objetivo: entender a mudança de linguagem, os comandos mais usados em C e a forma de escrever o mesmo conteúdo em C#.

Conceitos desta aula

  • Transição de linguagem
  • Comandos de entrada e saída
  • Estruturas de decisão e repetição
  • Funções, vetores e estruturas
  • Diferença entre C e C#

Definições

Transição de linguagem é o processo de levar a lógica que foi escrita em uma linguagem para outra linguagem.

C é uma linguagem mais próxima do hardware e usa funções soltas no programa.

C# é uma linguagem com suporte a orientação a objetos, classes e métodos organizados em tipos.

Como pensar na transição

A lógica dos exercícios continua a mesma. O que muda é a sintaxe e a forma de organizar o código.

Em C, a turma usou printf, scanf, if, for, while, switch, funções, vetores e struct. Em C#, esses recursos continuam existindo, mas com outros nomes e com mais apoio da linguagem.

Exercício 01 - C e C#

C:

#include <stdio.h>
  int main(){
    float total, preco;
    int paes;

    printf("Digite quantos paes vai levar: ");
    scanf("%d",&paes);

    printf("Digite qual o preco: ");
    scanf("%f",&preco);

    total = paes * preco;

    printf("O total e: %f",total);

    return 0;
  }

Versão em C#:

using System;

  class Program
  {
    static void Main()
    {
      Console.Write("Digite quantos paes vai levar: ");
      int paes = int.Parse(Console.ReadLine());

      Console.Write("Digite qual o preco: ");
      float preco = float.Parse(Console.ReadLine());

      float total = paes * preco;
      Console.WriteLine("O total e: " + total);
    }
  }

Exercício 03 - C e C#

C:

#include <stdio.h>
  int main(){
    float HT, VH, PD, SB, TD, SL;

    printf("Digite HT: ");
    scanf("%f",&HT);

    printf("Digite VH: ");
    scanf("%f",&VH);

    printf("Digite PD: ");
    scanf("%f",&PD);

    SB = HT * VH;
    TD = SB - (SB*(PD/100));
    SL = SB - TD;

    printf("\nO valor do SB: %.2f",SB);
    printf("\nO valor do TD: %.2f",TD);
    printf("\nO valor do SL: %.2f",SL);

    return 0;
  }

Versão em C#:

using System;

  class Program
  {
    static void Main()
    {
      Console.Write("Digite HT: ");
      float HT = float.Parse(Console.ReadLine());

      Console.Write("Digite VH: ");
      float VH = float.Parse(Console.ReadLine());

      Console.Write("Digite PD: ");
      float PD = float.Parse(Console.ReadLine());

      float SB = HT * VH;
      float TD = SB - (SB * (PD / 100));
      float SL = SB - TD;

      Console.WriteLine("O valor do SB: " + SB.ToString("F2"));
      Console.WriteLine("O valor do TD: " + TD.ToString("F2"));
      Console.WriteLine("O valor do SL: " + SL.ToString("F2"));
    }
  }
