Aula 01 - Transicao de C para C#

Objetivo: compreender como reaproveitar a mesma logica aprendida em C, mudando a sintaxe e a organizacao do codigo para C#.

Por que esta transicao e importante

Voce nao esta recomecando do zero. O que ja aprendeu em C continua valendo: leitura de dados, calculos, estruturas de decisao, repeticao e organizacao em funcoes.

O que muda e a forma de escrever. Em C#, o codigo fica mais organizado em tipos e metodos, com bibliotecas padrao que facilitam tarefas comuns.

A regra principal desta aula e simples: a logica permanece, a sintaxe muda.

Entrada de dados: o que muda na pratica

Em C, scanf ja coloca o valor no tipo certo quando a mascara esta correta. Em C#, Console.ReadLine() sempre devolve texto. Por isso, voce converte o valor manualmente.

Exemplo em C

#include <stdio.h>

int main() {
    int idade;

    printf("Digite sua idade: ");
    scanf("%d", &idade);

    printf("Idade informada: %d\n", idade);
    return 0;
}

Exemplo equivalente em C#

using System;

class Program
{
    static void Main()
    {
        Console.Write("Digite sua idade: ");
        int idade = int.Parse(Console.ReadLine());

        Console.WriteLine("Idade informada: " + idade);
    }
}

Repare na equivalencia:

  • printf vira Console.Write/WriteLine.
  • scanf vira Console.ReadLine + int.Parse.
  • A variavel continua sendo int, com o mesmo significado matematico.

Decisao e repeticao: a logica continua igual

Quando voce aprendeu if, for e while em C, ja aprendeu o raciocinio principal. Em C#, voce usa os mesmos blocos de decisao e repeticao.

using System;

class Program
{
    static void Main()
    {
        for (int i = 1; i <= 5; i++)
        {
            if (i % 2 == 0)
            {
                Console.WriteLine(i + " e par");
            }
            else
            {
                Console.WriteLine(i + " e impar");
            }
        }
    }
}

O codigo acima usa a mesma ideia que voce ja praticou: percorrer valores e classificar cada um por uma condicao.

Erros comuns de quem esta migrando

  1. Esquecer que ReadLine retorna texto.
  2. Tentar usar scanf em C#.
  3. Confundir Write com WriteLine.
  4. Nao validar entrada quando o usuario pode digitar valor invalido.

Com pratica, esses pontos viram rotina. O mais importante e manter o foco na sequencia logica da solucao.

Resumo da aula

A transicao de C para C# nao exige abandonar o que voce sabe. Voce aproveita a base de logica e aprende uma nova forma de expressar essa base.

Ao final desta etapa, voce deve conseguir:

  • Escrever entrada e saida em C#.
  • Converter texto para numeros.
  • Reproduzir em C# algoritmos simples que ja funcionavam em C.

Atividade

Escolha um exercicio em C que voce ja resolveu e reescreva em C# mantendo a mesma logica. Depois, anote em duas colunas:
