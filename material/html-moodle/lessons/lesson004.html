Aula 04 - Atributos e estado

Objetivo: representar dados com atributos e entender estado.

Conceitos desta aula

  • Atributo
  • Estado
  • Tipo de dado

Definicoes

Atributo e um dado da classe. Estado e o conjunto dos valores atuais dos atributos.

Explicacao curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

class Conta
{
    public string Titular;
    public decimal Saldo;
}

Conta c = new Conta();
c.Titular = "Maria";

Resumo

Quando os valores mudam, o estado do objeto muda.

Atividade

Defina a classe Produto com Nome, Quantidade e Preco.
