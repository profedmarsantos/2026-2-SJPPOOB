Módulo 04

Atributos e Estado

Objetivo: representar dados com atributos e acompanhar como o estado de um objeto muda durante a execução.

Introdução teórica

Na POO, cada objeto guarda dados em atributos. Esses dados formam o estado atual do objeto.

Quando um valor de atributo muda, o estado também muda. Essa mudança precisa ser planejada para manter o programa correto.

Conceitos essenciais desta aula

  • Atributo: campo que armazena um dado do objeto, como nome, saldo ou quantidade.
  • Estado: conjunto dos valores atuais de todos os atributos do objeto.
  • Tipo de dado: regra que define qual valor um atributo pode armazenar.

Exemplo em C#

Arquivo 1: Produto.cs

using System;

public class Produto
{
    public string Nome;
    public int Quantidade;
    public decimal Preco;

    public void ExibirEstado()
    {
        Console.WriteLine("Nome: " + Nome);
        Console.WriteLine("Quantidade: " + Quantidade);
        Console.WriteLine("Preco: " + Preco);
    }
}

Arquivo 2: Program.cs

using System;

class Program
{
    static void Main()
    {
        Produto p = new Produto();
        p.Nome = "Caderno";
        p.Quantidade = 10;
        p.Preco = 24.90m;

        p.ExibirEstado();

        p.Quantidade = 8;
        Console.WriteLine("Após venda de 2 unidades:");
        p.ExibirEstado();
    }
}

Leitura guiada do exemplo

  1. A classe Produto define três atributos para representar seu estado.
  2. O método ExibirEstado() mostra os valores atuais do objeto.
  3. No Main, o objeto recebe os valores iniciais.
  4. Depois da alteração em Quantidade, o estado muda e a saída confirma a mudança.

Exercícios de fixação

  1. Exercício 1: crie a classe Aluno com os atributos Nome, Turma e NotaFinal.

    Ver resposta

    public string Nome;

  2. Exercício 2: explique o que muda no estado do objeto quando o atributo Quantidade passa de 20 para 15.

    Ver resposta

    O estado do objeto foi alterado porque um dos seus atributos mudou de valor. Os demais atributos podem continuar iguais.

  3. Exercício 3: adicione um método ReporEstoque(int valor) na classe Produto para somar unidades no atributo Quantidade.

    Ver resposta 
    public void ReporEstoque(int valor)
{
    Quantidade = Quantidade + valor;
}

  4. Exercício 4: escreva um programa que crie dois objetos Produto com valores diferentes e mostre o estado de cada um.

    Ver resposta

    Use duas instâncias, como p1 e p2, atribua dados diferentes e chame ExibirEstado() para cada uma.

Resumo da aula

Atributos guardam dados do objeto. O conjunto desses dados forma o estado.

Controlar mudanças de estado é essencial para evitar inconsistências no sistema.

Atividade guiada

Passo 1: crie a classe ContaEstudante com os atributos Nome, Curso e SaldoCreditos.

Passo 2: adicione um método para mostrar o estado atual.

Passo 3: altere o saldo e mostre novamente para verificar a mudança de estado.
