Módulo 06

Encapsulamento

Objetivo: proteger dados internos e aplicar regras de validação para manter consistência do estado.

Introdução teórica

Encapsulamento é a prática de esconder dados internos e permitir alterações apenas por operações controladas.

Essa abordagem reduz erros, porque impede mudanças diretas sem validação.

Conceitos essenciais desta aula

  • Dado privado: só pode ser acessado dentro da própria classe.
  • Regra de acesso: validação aplicada antes de alterar o estado.
  • Método público: ponto de entrada seguro para operações externas.

Exemplo em C#

using System;

class Conta
{
    private decimal saldo;

    public void Depositar(decimal valor)
    {
        if (valor > 0)
            saldo += valor;
    }

    public bool Sacar(decimal valor)
    {
        if (valor <= 0)
            return false;

        if (valor > saldo)
            return false;

        saldo -= valor;
        return true;
    }

    public decimal ObterSaldo()
    {
        return saldo;
    }
}

class Program
{
    static void Main()
    {
        Conta c = new Conta();
        c.Depositar(200);

        bool saqueOk = c.Sacar(50);
        Console.WriteLine("Saque realizado: " + saqueOk);
        Console.WriteLine("Saldo atual: " + c.ObterSaldo());
    }
}

Leitura guiada do exemplo

  1. O atributo saldo é privado e não pode ser alterado diretamente fora da classe.
  2. O método Depositar só aceita valores positivos.
  3. O método Sacar valida valor e saldo disponível antes de alterar o estado.
  4. O método ObterSaldo permite consulta segura do valor atual.

Resumo da aula

Encapsulamento protege dados internos e centraliza regras de alteração de estado.

Com essa prática, o código fica mais seguro e previsível.
