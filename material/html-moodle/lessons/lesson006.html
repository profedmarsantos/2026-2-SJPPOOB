Aula 06 - Encapsulamento

Objetivo: proteger dados internos e aplicar regras de acesso.

Conceitos desta aula

  • Encapsulamento
  • Dado privado
  • Regra de acesso

Definições

Encapsulamento protege dados internos. Dados privados so podem ser alterados por regras da classe.

Explicação curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

class Conta
{
    private decimal saldo;

    public void Depositar(decimal valor)
    {
        if (valor > 0) saldo += valor;
    }
}

Resumo

Encapsulamento reduz erros de alteracao de estado.

Atividade

Adicione regra para impedir deposito com valor zero.
