Aula 11 - Polimorfismo

Objetivo: usar o mesmo metodo com comportamentos diferentes.

Conceitos desta aula

  • Polimorfismo
  • Sobrescrita
  • virtual
  • override

Definicoes

Polimorfismo permite tratar objetos diferentes por uma referencia comum.

Explicacao curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

class Animal
{
    public virtual void Som() { Console.WriteLine("Som"); }
}

class Gato : Animal
{
    public override void Som() { Console.WriteLine("Miau"); }
}

Resumo

Polimorfismo melhora extensao sem quebrar codigo existente.

Atividade

Crie duas classes derivadas sobrescrevendo o mesmo metodo.
