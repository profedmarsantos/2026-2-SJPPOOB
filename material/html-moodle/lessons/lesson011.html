Módulo 11 - Polimorfismo

Objetivo: Usar o Mesmo Método com Comportamentos Diferentes.

Conceitos Desta Aula

  • Polimorfismo
  • Sobrescrita
  • virtual
  • override

Definições

Polimorfismo permite tratar objetos diferentes por uma referencia comum.

Explicação Curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo Curto

class Animal
{
    public virtual void Som() { Console.WriteLine("Som"); }
}

class Gato : Animal
{
    public override void Som() { Console.WriteLine("Miau"); }
}

Resumo

Polimorfismo melhora extensão sem quebrar código existente.

Atividade

Crie duas classes derivadas sobrescrevendo o mesmo método.
