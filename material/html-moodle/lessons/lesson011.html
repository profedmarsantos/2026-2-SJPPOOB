Módulo 11

Polimorfismo

Objetivo: usar a mesma chamada de metodo com comportamentos diferentes em classes derivadas.

Introducao teorica

Polimorfismo permite tratar objetos diferentes por uma referencia da classe base.

O metodo chamado e decidido conforme o tipo real do objeto em execucao.

Conceitos essenciais desta aula

  • virtual: permite que o metodo da classe base seja sobrescrito.
  • override: substitui o comportamento herdado na classe derivada.
  • Referencia comum: variavel da classe base apontando para objetos derivados.

Exemplo em C#

using System;
using System.Collections.Generic;

class Animal
{
    public virtual void EmitirSom()
    {
        Console.WriteLine("Som generico");
    }
}

class Gato : Animal
{
    public override void EmitirSom()
    {
        Console.WriteLine("Miau");
    }
}

class Cachorro : Animal
{
    public override void EmitirSom()
    {
        Console.WriteLine("Au au");
    }
}

class Program
{
    static void Main()
    {
        List animais = new List
        {
            new Gato(),
            new Cachorro()
        };

        foreach (Animal a in animais)
        {
            a.EmitirSom();
        }
    }
}

Leitura guiada do exemplo

  1. A classe base define EmitirSom() como virtual.
  2. As classes derivadas sobrescrevem o metodo com override.
  3. A lista usa a referencia comum Animal para guardar tipos diferentes.
  4. No foreach, a mesma chamada executa comportamentos diferentes.

  3. Exercicio 3: explique por que polimorfismo reduz acoplamento.

    Ver resposta

  4. Exercicio 4: monte uma lista da classe base com dois objetos derivados e execute o mesmo metodo.

    Ver resposta

Resumo da aula

Polimorfismo permite estender comportamento sem alterar quem consome a classe base.

Virtual e override sao os recursos principais para implementar essa estrategia em C#.

Passo 2: crie duas classes derivadas com mensagens diferentes.

Passo 3: use uma lista de Relatorio e chame Gerar() para cada item.
