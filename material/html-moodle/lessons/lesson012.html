Aula 12 - Abstracao

Objetivo: focar no essencial e ocultar detalhes internos.

Conceitos desta aula

  • Abstracao
  • Classe abstrata
  • Metodo abstrato

Definicoes

Abstracao define o que e necessario para usar um objeto sem expor toda implementacao.

Explicacao curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

abstract class Forma
{
    public abstract double Area();
}

Resumo

Abstracao simplifica uso de componentes do sistema.

Atividade

Defina uma classe abstrata Veiculo com metodo abstrato Mover().
