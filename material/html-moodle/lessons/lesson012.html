Aula 12 - abstração

Objetivo: focar no essencial e ocultar detalhes internos.

Conceitos desta aula

  • abstração
  • Classe abstrata
  • método abstrato

Definições

abstração define o que e necessário para usar um objeto sem expor toda implementacao.

Explicação curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

abstract class Forma
{
    public abstract double Area();
}

Resumo

abstração simplifica uso de componentes do sistema.

Atividade

Defina uma classe abstrata Veiculo com método abstrato Mover().
