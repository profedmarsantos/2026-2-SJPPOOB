Módulo 12

Abstracao

Objetivo: focar no essencial da modelagem com classes e metodos abstratos.

Introducao teorica

Abstracao destaca o que e obrigatorio no comportamento de um tipo e oculta detalhes internos.

Em C#, isso pode ser feito com classes abstratas e metodos abstratos.

Conceitos essenciais desta aula

  • Classe abstrata: classe que nao pode ser instanciada diretamente.
  • Metodo abstrato: metodo sem corpo, obrigando implementacao nas classes filhas.
  • Especializacao: cada classe derivada implementa o comportamento conforme sua necessidade.

Exemplo em C#

Arquivo 1: Forma.cs

using System;

public abstract class Forma
{
    public abstract double CalcularArea();
}

Arquivo 2: Retangulo.cs

using System;

public class Retangulo : Forma
{
    public double Base;
    public double Altura;

    public override double CalcularArea()
    {
        return Base * Altura;
    }
}

Arquivo 3: Circulo.cs

using System;

public class Circulo : Forma
{
    public double Raio;

    public override double CalcularArea()
    {
        return 3.14 * Raio * Raio;
    }
}

Arquivo 4: Program.cs

using System;

class Program
{
    static void Main()
    {
        Retangulo r = new Retangulo();
        r.Base = 4;
        r.Altura = 3;

        Circulo c = new Circulo();
        c.Raio = 2;

        Console.WriteLine("Area do retangulo: " + r.CalcularArea());
        Console.WriteLine("Area do circulo: " + c.CalcularArea());
    }
}

Leitura guiada do exemplo

  1. Forma define contrato comum com CalcularArea().
  2. Retangulo implementa com base vezes altura.
  3. Circulo implementa com formula da area do circulo.
  4. A classe abstrata organiza um padrao, e cada classe concreta detalha o calculo.

Exercicios de fixacao

  1. Exercicio 1: crie a classe abstrata Veiculo com metodo abstrato Mover().

    Ver resposta 
    abstract class Veiculo
{
    public abstract void Mover();

  2. Exercicio 2: implemente Carro e Bicicleta herdando de Veiculo.

    Ver resposta

    Cada classe deve sobrescrever Mover() com sua propria mensagem de deslocamento.

  3. Exercicio 3: explique por que classe abstrata nao pode ser instanciada.

    Ver resposta

    Porque ela representa um modelo incompleto, que depende da implementacao das classes derivadas.

  4. Exercicio 4: crie um metodo abstrato e duas implementacoes diferentes em classes filhas.

    Ver resposta

    Exemplo: metodo Calcular() na base e formulas diferentes em duas classes derivadas.

Resumo da aula

Abstracao define contratos claros para classes relacionadas.

Com classe abstrata, o sistema ganha organizacao e consistencia de implementacao.

Passo 2: implemente classes Mensalista e Horista.

Passo 3: mostre no console o resultado de cada implementacao.
