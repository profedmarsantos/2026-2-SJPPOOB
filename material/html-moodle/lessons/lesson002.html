Aula 02 - Introducao a programacao orientada a objetos

Objetivo: iniciar orientacao a objetos em C# e definir os termos principais.

Conceitos desta aula

  • Programacao orientada a objetos
  • Classe
  • Objeto
  • Atributo
  • Metodo

Definicoes

Programacao orientada a objetos organiza o programa em classes. Classe define dados e acoes. Objeto e uma criacao da classe.

Explicacao curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

class Produto
{
    public string Nome;
    public decimal Preco;
}

Produto p = new Produto();
p.Nome = "Caderno";
p.Preco = 12.50m;

Resumo

POO comeca com classe e objeto. Esta base sera usada em todo o curso.

Atividade

Crie uma classe Aluno com Nome e Idade.
