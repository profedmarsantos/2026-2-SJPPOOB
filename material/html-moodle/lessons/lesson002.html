Módulo 02

Introdução à Programação Orientada a Objetos

Objetivo: entender o que é POO e usar classe e objeto para modelar situações reais em C#.

O que muda na programação orientada a objetos

Na programação estruturada, você pensa primeiro em funções e passos. Na programação orientada a objetos, você organiza o sistema em modelos de entidades e nas ações dessas entidades.

Em outras palavras: em vez de pensar apenas no que o programa faz, você também pensa em quem participa do problema e quais dados e comportamentos cada participante possui.

Conceitos essenciais desta aula

Entidade

Elemento do problema real que será representado no sistema por classe e objeto.

Classe

Modelo de código que define estrutura e comportamento para criar objetos.

Atributo

Informação armazenada no objeto, como nome, preço, idade ou saldo.

Método

Ação que o objeto executa, implementando regras e operações do modelo.

Instância

Cada objeto gerado a partir de uma classe, representando um caso específico.

Objeto

Instância concreta criada a partir de uma classe, com dados próprios.

Resumo: primeiro identificamos a entidade; depois definimos a classe; em seguida declaramos atributos e métodos; por fim criamos instâncias e objetos para uso no programa.

Classe como modelo reutilizável

Se uma escola precisa guardar dados de vários alunos, em vez de criar variáveis separadas para cada aluno, criamos uma classe Aluno como modelo. Depois, geramos quantos objetos forem necessários.

Pense assim: a classe é como uma planta técnica. O objeto é a construção real feita com essa planta.

Esse modelo facilita manutenção, leitura e crescimento do sistema.

Exemplos por conceito

Antes do exemplo completo, vamos identificar cada conceito separadamente com blocos curtos de código.

1) Entidade

Conceito: entidade é o elemento do problema real que será representado no programa.

Entidade representada neste caso: aluno.

2) Classe

Conceito: a classe é o modelo que representa a entidade.

class Aluno
{
}

Quem é a classe no código: Aluno.

3) Atributo

Conceito: atributo é um dado armazenado no objeto.

class Aluno
{
    public string Nome;
    public int Idade;
}

Quais são os atributos no código: Nome e Idade.

4) Método

Conceito: método é a ação definida na classe.

class Aluno
{
    public string Nome;

    public void ExibirNome()
    {
        Console.WriteLine("Nome: " + Nome);
    }
}

Qual é o método no código: ExibirNome.

5) Instância

Conceito: instanciar é criar ocorrências da classe com new.

Aluno a1 = new Aluno();
Aluno a2 = new Aluno();

Quais são as instâncias no código: a1 e a2.

6) Objeto

Conceito: objeto é cada instância em uso, com valores próprios nos atributos.

Aluno a1 = new Aluno();
    a1.Nome = "Ana";
    a1.Idade = 15;

Quem é o objeto no código: a1.

7) Junção progressiva (prévia do exemplo completo)

Conceito: agora unimos entidade, classe, atributos, método, instâncias e objetos em um mesmo fluxo. Como os alunos criam arquivos separados, a classe do modelo e a classe principal ficam em arquivos diferentes.

Arquivo 1: Aluno.cs

using System;

public class Aluno
{
    public string Nome;
    public int Idade;

    public void ExibirDados()
    {
        Console.WriteLine("Nome: " + Nome);
        Console.WriteLine("Idade: " + Idade);
    }
}

Arquivo 2: Program.cs

using System;

class Program
{
    static void Main()
    {
        Aluno a1 = new Aluno();
        a1.Nome = "Ana";
        a1.Idade = 15;

        Aluno a2 = new Aluno();
        a2.Nome = "Bruno";
        a2.Idade = 16;

        a1.ExibirDados();
        a2.ExibirDados();
    }
}

Próximo passo: ler o primeiro exemplo completo com todos os conceitos já identificados.

Primeiro exemplo completo

Neste exemplo, a classe define os dados e uma ação. Em seguida, criamos dois objetos diferentes do mesmo modelo.

Arquivo 1: Aluno.cs

using System;

public class Aluno
{
    public string Nome;
    public int Idade;

    public void ExibirDados()
    {
        Console.WriteLine("Nome: " + Nome);
        Console.WriteLine("Idade: " + Idade);
    }
}

Arquivo 2: Program.cs

using System;

class Program
{
    static void Main()
    {
        Aluno a1 = new Aluno();
        a1.Nome = "Ana";
        a1.Idade = 15;

        Aluno a2 = new Aluno();
        a2.Nome = "Bruno";
        a2.Idade = 16;

        a1.ExibirDados();
        a2.ExibirDados();
    }
}

Observe o reaproveitamento: uma única classe gerou dois objetos com valores diferentes.

O que significa public

No código anterior, aparecem palavras como public string Nome; e public void ExibirDados(). Esse termo é um modificador de acesso.

Ele indica que o atributo ou o método pode ser usado por outras partes do programa, inclusive por outras classes.

Em termos simples: public torna o conteúdo da classe visível para fora dela.

Isso é importante porque, ao criar objetos, o programa precisa acessar seus dados e executar seus métodos.

Mais adiante, você vai conhecer outros modificadores, como private, que restringem esse acesso.

Passo a passo para leitura do código

  1. Definimos a classe Aluno com atributos Nome e Idade.
  2. Criamos o método ExibirDados para mostrar as informações.
  3. No Main, criamos os objetos a1 e a2 usando new.
  4. Preenchemos cada objeto com dados próprios.
  5. Chamamos o mesmo método para cada objeto.

Esse processo será repetido ao longo da disciplina em modelos cada vez mais completos.

Comparação curta: variáveis soltas x classe

Sem classe Com classe
Muitas variáveis espalhadas Dados agrupados por entidade
Repetição de blocos parecidos Reaproveitamento de modelo
Manutenção difícil quando cresce Estrutura mais organizada e escalável

Resumo da Aula

POO organiza o código por modelos reutilizáveis. A classe define o formato e o comportamento; o objeto representa um caso real desse formato.

Com isso, o código fica mais fácil de entender, manter e expandir.

Atividade guiada

Crie uma classe Produto com os atributos Nome e Preço e um método Exibir para mostrar os dados.

Depois, crie dois objetos diferentes e apresente os resultados na tela.
