Aula 02 - Introducao a programacao orientada a objetos

Objetivo: entender o que e POO e usar os conceitos de classe e objeto para modelar situacoes reais em C#.

O que muda quando entramos em POO

Na programacao estruturada, voce pensa primeiro em funcoes e passos. Na programacao orientada a objetos, voce organiza o sistema em modelos de entidades e nas acoes dessas entidades.

Em outras palavras: em vez de pensar apenas no que o programa faz, voce tambem pensa em quem participa do problema (Aluno, Produto, Conta, Pedido) e quais dados e comportamentos cada participante possui.

Conceitos essenciais desta aula

Classe Objeto Atributo Metodo Instancia

Classe e a definicao de um modelo de codigo que iremos reutilizar sempre que precisarmos representar algo da vida real mais de uma vez.

Objeto e uma instancia concreta criada a partir da classe.

Atributo representa uma informacao do objeto (exemplo: nome, preco, saldo).

Metodo representa uma acao que o objeto sabe executar.

Classe como modelo reutilizavel

Imagine que uma escola precisa guardar dados de varios alunos. Em vez de criar variaveis separadas para cada aluno, criamos uma classe Aluno como modelo. Depois, geramos quantos objetos forem necessarios.

Pense assim: a classe e como uma planta tecnica. O objeto e a construcao real feita com essa planta.

Esse modelo facilita manutencao, leitura e crescimento do sistema.

Primeiro exemplo completo

Neste exemplo, a classe define os dados e uma acao. Em seguida, criamos dois objetos diferentes do mesmo modelo.

using System;

class Aluno
{
    public string Nome;
    public int Idade;

    public void ExibirDados()
    {
        Console.WriteLine("Nome: " + Nome + " | Idade: " + Idade);
    }
}

class Program
{
    static void Main()
    {
        Aluno a1 = new Aluno();
        a1.Nome = "Ana";
        a1.Idade = 15;

        Aluno a2 = new Aluno();
        a2.Nome = "Bruno";
        a2.Idade = 16;

        a1.ExibirDados();
        a2.ExibirDados();
    }
}

Observe o reaproveitamento: uma unica classe gerou dois objetos com valores diferentes.

Passo a passo para leitura do codigo

  1. Definimos a classe Aluno com atributos Nome e Idade.
  2. Criamos o metodo ExibirDados para mostrar as informacoes.
  3. No Main, criamos os objetos a1 e a2 usando new.
  4. Preenchemos cada objeto com dados proprios.
  5. Chamamos o mesmo metodo para cada objeto.

Esse processo sera repetido ao longo da disciplina em modelos cada vez mais completos.

Comparacao curta: variaveis soltas x classe

Sem classe Com classe
Muitas variaveis espalhadas Dados agrupados por entidade
Repeticao de blocos parecidos Reaproveitamento de modelo
Manutencao dificil quando cresce Estrutura mais organizada e escalavel

Resumo da aula

POO organiza o codigo por modelos reutilizaveis. A classe define o formato e o comportamento; o objeto representa um caso real desse formato.

Com isso, o codigo fica mais facil de entender, manter e expandir.

Atividade guiada

Crie uma classe Produto com os atributos Nome e Preco e um metodo Exibir para mostrar os dados.

Depois crie dois objetos diferentes e apresente os resultados na tela.
