Módulo 14

Colecoes e Listas

Objetivo: armazenar varios objetos em memoria usando List<T> e percorrer os dados com seguranca.

Introducao teorica

Quando o sistema precisa lidar com varios itens, variaveis isoladas nao sao suficientes.

As colecoes organizam dados em estruturas dinamicas. Em C#, a mais comum e List<T>.

Conceitos essenciais desta aula

  • Colecao: estrutura que guarda varios elementos.
  • List<T>: colecao generica com insercao, remocao e busca simples.
  • Iteracao: percurso dos elementos com for ou foreach.

Exemplo em C#

using System;
using System.Collections.Generic;

class Aluno
{
    public string Nome { get; set; }
    public double Nota { get; set; }
}

class Program
{
    static void Main()
    {
        List alunos = new List();

        alunos.Add(new Aluno { Nome = "Ana", Nota = 8.5 });
        alunos.Add(new Aluno { Nome = "Bruno", Nota = 7.0 });
        alunos.Add(new Aluno { Nome = "Caio", Nota = 9.2 });

        foreach (Aluno aluno in alunos)
        {
            Console.WriteLine(aluno.Nome + " - Nota: " + aluno.Nota);
        }

        alunos.RemoveAt(1);
        Console.WriteLine("Total apos remocao: " + alunos.Count);
    }
}

Leitura guiada do exemplo

  1. A lista e criada com o tipo Aluno.
  2. Cada item e adicionado com Add.
  3. O foreach percorre todos os objetos para exibicao.
  4. RemoveAt(1) remove o item da posicao 1 e Count mostra a nova quantidade.

nomes.Add("Lia");
nomes.Add("Joao");
nomes.Add("Marcos");

  2. Exercicio 2: percorra a lista com foreach e mostre os itens.

  3. Exercicio 3: explique quando usar lista em vez de variaveis separadas.

    Ver resposta

    Quando a quantidade de itens pode crescer ou variar, a lista facilita insercao, remocao e percurso.

  4. Exercicio 4: crie uma lista de objetos Produto e mostre nome e preco de cada item.

    Ver resposta

Resumo da aula

Listas sao fundamentais para programas que manipulam varios registros.

Com List<T>, o codigo fica mais flexivel e pronto para evoluir.

Passo 2: crie uma List<Produto> e adicione quatro itens.
