Módulo 08

Propriedades

Objetivo: controlar leitura e escrita de atributos com get e set, aplicando validações simples.

1. Introdução teórica

Propriedade é a forma padrão de expor dados em C#. Ela permite ler e escrever valores com controle.

Com get e set, você mantém encapsulamento e validação no mesmo ponto.

2. Conceitos essenciais desta aula

  • Propriedade: membro que fornece acesso controlado a um valor.
  • get: bloco responsável por devolver o valor atual.
  • set: bloco responsável por validar e atribuir novo valor.

3. Exemplo em C#

Arquivo 1: Aluno.cs

using System;

public class Aluno
{
    private int nota;

    public int Nota
    {
        get { return nota; }
        set
        {
            if (value >= 0 && value <= 10)
                nota = value;
        }
    }

    public string Nome { get; set; }
}

Arquivo 2: Program.cs

using System;

class Program
{
    static void Main()
    {
        Aluno a = new Aluno();
        a.Nome = "Bianca";
        a.Nota = 8;

        Console.WriteLine("Nome: " + a.Nome);
        Console.WriteLine("Nota: " + a.Nota);

        a.Nota = 15;
        Console.WriteLine("Nota após tentativa inválida: " + a.Nota);
    }
}

4. Leitura guiada do exemplo

  1. O campo privado nota não é acessado diretamente fora da classe.
  2. A propriedade Nota valida o intervalo entre 0 e 10 no set.
  3. A propriedade Nome usa formato automático (get; set;).
  4. Ao tentar atribuir 15, o valor não é aceito e a nota permanece 8.

6. Exercícios integradores

Os exercícios a seguir integram propriedades, encapsulamento e validação de dados.

  1. 6.1 Exercício: ContaBancaria

    Objetivo

    Criar a classe ContaBancaria para representar uma conta com saldo protegido.

    Diagrama de Classe

    classDiagram class ContaBancaria { -titular: string -saldo: double +ContaBancaria(titular: string, saldo: double) +Titular: string +Saldo: double +ExibirSaldo() void } class Program { ~Main() void$ } Program ..> ContaBancaria : cria e usa

    Conhecimentos necessários

    • Conceito de classe e objeto.
    • Modificadores de acesso private e public.
    • Uso de construtores para inicialização.
    • Uso de propriedades com blocos get e set.

    Conceitos principais

    Usar construtores para inicializar objetos e propriedades para proteger dados internos.

    Definições

    • Encapsulamento: proteção de dados privados por meio de propriedades públicas.
    • Construtor: método chamado automaticamente na criação de um objeto.

    Explicação

    Use um construtor para receber os valores iniciais e propriedades com lógica para impedir dados inválidos.

    Regras

    1. Crie os atributos privados titular (string) e saldo (double).
    2. Crie um construtor que receba o titular e o saldo inicial.
    3. Crie a propriedade Saldo. Valores negativos não podem alterar o saldo.
    4. Crie a propriedade Titular.
    5. Crie o método ExibirSaldo e teste um valor negativo no Main.

    Dados de entrada (exemplo)

    Titular: Ana
    Saldo inicial: 100,00

    Processamento esperado

    • O construtor atribui o titular e o saldo inicial.
    • A propriedade impede a alteração para um saldo negativo.
    • O método exibe os dados da conta.

    Resultado esperado

    Titular: Ana
Saldo: R$ 100,00
    Ver solução em C#

    Arquivo 1: ContaBancaria.cs

    using System;

class ContaBancaria
{
    private string titular;
    private double saldo;

    public ContaBancaria(string titular, double saldo)
    {
        this.titular = titular;
        Saldo = saldo;
    }

    public string Titular
    {
        get { return titular; }
        set { titular = value; }
    }

    public double Saldo
    {
        get { return saldo; }
        set
        {
            if (value >= 0)
                saldo = value;
        }
    }

    public void ExibirSaldo()
    {
        Console.WriteLine("Titular: " + titular);
        Console.WriteLine("Saldo: R$ " + saldo);
    }
}

    Arquivo 2: Program.cs

    using System;

class Program
{
    static void Main()
    {
        ContaBancaria minhaConta = new ContaBancaria("Ana", 100.00);
        minhaConta.Saldo = -50;
        minhaConta.ExibirSaldo();
    }
}

    Explicação da solução

    • Atributos privados: protegem titular e saldo.
    • Construtor: inicializa o objeto no momento da criação.
    • Propriedade Saldo: impede valores negativos.
    • Método ExibirSaldo: mostra os dados formatados.

    Erros comuns

    • Acessar diretamente o atributo saldo fora da classe.
    • Esquecer this quando parâmetro e atributo têm o mesmo nome.
    • Permitir valores negativos no saldo.

    Resumo

    Construtores inicializam objetos com dados válidos. Propriedades controlam alterações nos dados privados.

  2. 6.2 Exercício: ProdutoLoja

    Objetivo

    Criar a classe ProdutoLoja para representar um item com controle de quantidade em estoque.

    Diagrama de Classe

    classDiagram class ProdutoLoja { -nome: string -quantidade: int +ProdutoLoja(nome: string, quantidade: int) +Nome: string +Quantidade: int +ExibirEstoque() void } class Program { ~Main() void$ } Program ..> ProdutoLoja : cria e usa

    Conhecimentos necessários

    • Modificadores de acesso private e public.
    • Uso de propriedades com blocos get e set.
    • Uso de construtores para inicialização.

    Conceitos principais

    Impedir a alteração direta de dados privados e aplicar restrições por meio de propriedades.

    Definições

    • Encapsulamento: proteção dos dados internos da classe.
    • Validação: regra aplicada para aceitar ou recusar novos valores.

    Explicação

    Use propriedades para verificar se os valores atendem às regras antes de alterar os atributos privados.

    Regras

    1. Crie os atributos privados nome (string) e quantidade (int).
    2. Crie um construtor que receba o nome e a quantidade inicial.
    3. Crie a propriedade Quantidade. Se o valor for negativo, mantenha a quantidade atual.
    4. Crie a propriedade Nome.
    5. Crie o método ExibirEstoque e teste a validação no Main.

    Dados de entrada (exemplo)

    Nome: Teclado
    Quantidade inicial: 15

    Processamento esperado

    • O construtor atribui os valores iniciais.
    • A propriedade aceita somente quantidade maior ou igual a zero.
    • O método exibe o estado atual do estoque.

    Resultado esperado

    Produto: Teclado
Quantidade: 15
    Ver solução em C#

    Arquivo 1: ProdutoLoja.cs

    using System;

class ProdutoLoja
{
    private string nome;
    private int quantidade;

    public ProdutoLoja(string nome, int quantidade)
    {
        this.nome = nome;
        Quantidade = quantidade;
    }

    public string Nome
    {
        get { return nome; }
        set { nome = value; }
    }

    public int Quantidade
    {
        get { return quantidade; }
        set
        {
            if (value >= 0)
                quantidade = value;
        }
    }

    public void ExibirEstoque()
    {
        Console.WriteLine("Produto: " + nome);
        Console.WriteLine("Quantidade: " + quantidade);
    }
}

    Arquivo 2: Program.cs

    using System;

class Program
{
    static void Main()
    {
        ProdutoLoja meuProduto = new ProdutoLoja("Teclado", 15);
        meuProduto.Quantidade = -2;
        meuProduto.ExibirEstoque();
    }
}

    Explicação da solução

    • Atributos privados: protegem o nome e a quantidade.
    • Construtor: inicializa os dados obrigatórios.
    • Propriedade Quantidade: valida o valor antes de atualizar o atributo.
    • Método ExibirEstoque: mostra os valores atuais.

    Erros comuns

    • Modificar diretamente o atributo quantidade.
    • Esquecer a validação de valores menores que zero.

    Resumo

    Propriedades com validação protegem o estado interno. O construtor garante que o objeto comece com dados consistentes.

Com validação no set, você protege o estado do objeto com regra simples e direta.

Crie um programa em C# para representar um produto armazenado em estoque.

Orientação de implementação

Use o diagrama como referência para criar a classe, as propriedades, o construtor e os métodos. Os testes abaixo definem as regras de comportamento que serão avaliadas.

  1. As propriedades Nome, Quantidade e Preco devem permitir consulta, mas não precisam de set público. Os três valores são definidos pelo construtor.
  2. O construtor deve verificar os valores iniciais e mostrar uma mensagem curta para cada erro:
    • Nome nulo ou vazio: Nome inválido.
    • Quantidade menor que zero: Quantidade inválida.
    • Preço menor que zero: Preço inválido.
  3. Não crie um set público para Quantidade. A quantidade só pode ser modificada pelos métodos AdicionarEstoque e Vender.
  4. O método AdicionarEstoque deve aceitar somente valores maiores que zero.
  5. O método Vender deve realizar a venda quando houver quantidade suficiente. Quando a venda não for possível, deve mostrar a mensagem A venda não é possível e não deve alterar a quantidade.
  6. O preço não será alterado depois da criação do objeto. Por isso, não é necessário criar um método para alterar Preco.
  7. O método CalcularValorDoEstoque deve consultar a quantidade e o preço e retornar a multiplicação dos dois valores.
  8. O preço e o valor total devem ser exibidos com duas casas decimais. Os rótulos da saída podem ser escritos de forma equivalente, mas os valores devem corresponder aos resultados esperados.
