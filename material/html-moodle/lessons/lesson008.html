Aula 08 - Propriedades

Objetivo: controlar leitura e escrita com get e set.

Conceitos desta aula

  • Propriedade
  • get
  • set

Definições

Propriedade expoe dados com controle. get le o valor. set altera o valor.

Explicação curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

class Aluno
{
    private int nota;

    public int Nota
    {
        get { return nota; }
        set { if (value >= 0 && value <= 10) nota = value; }
    }
}

Resumo

Propriedades são o caminho padrao para expor dados em C#.

Atividade

Crie a propriedade Idade com validacao para não aceitar negativo.
