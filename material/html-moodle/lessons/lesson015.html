Aula 15 - Acesso a banco de dados - conceitos

Objetivo: entender o que e banco de dados e como ele se conecta ao sistema.

Conceitos desta aula

  • Banco de dados
  • Tabela
  • Registro
  • Chave primaria

Definicoes

Banco de dados guarda informacoes de forma persistente. Tabela organiza dados em linhas e colunas.

Explicacao curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

-- exemplo conceitual

Colunas: Id, Nome, Turma

Resumo
