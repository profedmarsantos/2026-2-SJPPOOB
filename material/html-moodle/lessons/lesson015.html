Módulo 15

Acesso a Banco de Dados

Objetivo: entender os conceitos de persistencia e modelar tabelas com foco em uso no sistema em C#.

Introducao teorica

Banco de dados guarda informacoes de forma persistente, mesmo apos fechar o programa.

Antes de codificar, e necessario definir estrutura: tabelas, campos, tipos e chaves.

Conceitos essenciais desta aula

  • Tabela: conjunto de dados sobre uma entidade, como Alunos ou Produtos.
  • Registro: uma linha da tabela, representando um item cadastrado.
  • Campo: coluna com tipo de dado definido, como texto, numero ou data.
  • Chave primaria: campo unico que identifica cada registro.

Tabela comparativa de elementos

Elemento Funcao Exemplo
Tabela Organiza dados por tema Produtos
Registro Representa um item Produto com Id 1
Campo Define cada informacao Nome, Preco, Estoque
Chave primaria Identifica sem repeticao Id

Exemplo conceitual

-- Tabela de alunos
CREATE TABLE Alunos (
    Id INT PRIMARY KEY,
    Nome VARCHAR(80),
    Turma VARCHAR(10)
);

Leitura guiada do exemplo

  1. A tabela Alunos representa a entidade aluno.
  2. Id e a chave primaria, sem duplicidade.
  3. Nome e Turma guardam dados textuais.
  4. Essa estrutura sera usada nas proximas aulas para conexao e CRUD.

Resumo da aula

Acesso a banco começa pela modelagem correta dos dados.

Com tabela, campos e chave primaria bem definidos, a implementacao em C# fica mais segura.

Atividade guiada

Passo 1: modele as tabelas Clientes e Pedidos.

Passo 2: defina chaves primarias em cada tabela.

Passo 3: descreva qual campo conecta pedido ao cliente.

Passo 4: valide se nenhum campo essencial ficou sem tipo definido.
