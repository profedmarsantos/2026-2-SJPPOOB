Aula 10 - Heranca

Objetivo: reaproveitar codigo com classe base e derivada.

Conceitos desta aula

  • Heranca
  • Classe base
  • Classe derivada

Definicoes

Heranca permite criar uma classe nova a partir de outra existente.

Explicacao curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

class Pessoa
{
    public string Nome;
}

class Aluno : Pessoa
{
    public string Turma;
}

Resumo

Heranca reduz repeticao e facilita manutencao.

Atividade

Crie Funcionario herdando de Pessoa.
