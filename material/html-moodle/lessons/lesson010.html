Aula 10

Herança

Objetivo: construir classes relacionadas por herança, proteger o estado dos objetos e controlar votos em um array de candidatos.

1. Objetivo e resultado esperado

Ao concluir esta atividade, você terá um projeto C# com as classes Pessoa, Candidato, Eleitor e UrnaEletronica. A classe Program criará objetos e demonstrará as operações.

As regras de cadastro e votação ficarão nas classes do projeto. A classe Program demonstrará as chamadas e apresentará os resultados.

Este exercício é um simulador didático. Ele não valida a identidade de eleitores, não verifica o formato do CPF e não salva dados depois que o programa termina.

2. Pré-requisitos e conceitos

Antes de iniciar, você precisa saber criar classes e objetos, declarar atributos, escrever construtores, usar propriedades e percorrer um array com for.

  • Classe base: classe que concentra dados e operações comuns a outras classes.
  • Classe derivada: classe que herda os membros acessíveis de uma classe base. Em C#, a herança é indicada por :.
  • Encapsulamento: controle do acesso ao estado de um objeto. Nesta atividade, votos e situação de votação não poderão ser alterados diretamente pelo programa.

3. Regras do simulador

  1. Uma urna recebe uma capacidade maior que zero e cria um array com essa quantidade de posições.
  2. O cadastro retorna true somente quando o candidato foi incluído. Retorna false se o candidato for nulo, se o número já estiver cadastrado ou se não houver posição livre.
  3. A busca percorre os candidatos cadastrados. Se não encontrar o número, retorna null.
  4. Uma pessoa pode votar uma vez por instância de Eleitor. A urna recebe essa instância em cada operação de voto.
  5. Um número cadastrado soma um voto ao candidato correspondente. Um número não cadastrado soma um voto nulo.
  6. O voto branco usa uma operação própria e soma um voto branco.
  7. Voto válido, voto nulo e voto branco marcam o eleitor como votante. Se o eleitor já votou ou for nulo, a operação retorna false e não altera total algum.
  8. A verificação de voto repetido compara o estado do objeto recebido. Criar outro objeto Eleitor com o mesmo CPF não será reconhecido como a mesma pessoa.

Significado dos retornos: em operações de votação, true significa que o voto foi computado. Um número inexistente ainda é computado como voto nulo. false significa que o voto foi recusado porque o eleitor não pode votar.

5. Organização dos arquivos

O professor orientará a criação e a configuração do projeto. Considere as classes desta atividade como arquivos separados que pertencem ao mesmo projeto.

Use um arquivo para cada classe: Pessoa.cs, Candidato.cs, Eleitor.cs e UrnaEletronica.cs. O código demonstrativo ficará em Program.cs.

Os exemplos usam tipos anuláveis, como Candidato?, para indicar quando um valor pode ser null. O projeto precisa permitir tipos anuláveis.

6. Etapa 1: criar a classe base Pessoa

Objetivo: guardar nome e CPF uma única vez. As classes derivadas herdarão essas propriedades.

Arquivo: Pessoa.cs

public class Pessoa
{
    public string Nome { get; }
    public string Cpf { get; }

    public Pessoa(string nome, string cpf)
    {
        Nome = nome;
        Cpf = cpf;
    }
}
  1. Crie o arquivo Pessoa.cs.
  2. Declare as propriedades Nome e Cpf como públicas e somente para leitura.
  3. Declare o construtor Pessoa com os parâmetros nome e cpf.
  4. Atribua cada parâmetro à propriedade correspondente.

Verificação: uma instância de Pessoa recebe nome e CPF no construtor. Depois da criação, o programa não pode atribuir outro valor diretamente às propriedades.

7. Etapa 2: criar a classe Candidato

Objetivo: representar um candidato, reutilizando os dados de Pessoa e mantendo a contagem de votos encapsulada.

Arquivo: Candidato.cs

using System;

public class Candidato : Pessoa
{
    private int votos;

    public int Numero { get; }
    public string Partido { get; }
    public int Votos
    {
        get { return votos; }
    }

    public Candidato(string nome, string cpf, int numero, string partido)
        : base(nome, cpf)
    {
        if (numero <= 0)
        {
            throw new ArgumentOutOfRangeException(nameof(numero));
        }

        Numero = numero;
        Partido = partido;
        votos = 0;
    }

    internal void AdicionarVoto()
    {
        votos++;
    }
}
  1. Escreva : Pessoa depois do nome da classe. Isso declara a herança.
  2. Use : base(nome, cpf) no construtor para enviar os dados comuns ao construtor de Pessoa.
  3. Declare votos como privado. A propriedade pública Votos permite consultar a contagem, mas não permite atribuí-la.
  4. O método AdicionarVoto incrementa a contagem. O modificador internal permite que qualquer classe do mesmo assembly o chame. Neste exercício, a regra do projeto é que somente a urna chame esse método.
  5. O construtor recusa número menor ou igual a zero. ArgumentOutOfRangeException informa que o argumento está fora do intervalo permitido.

Verificação: crie um candidato com número positivo. Confirme que Nome e Cpf vêm de Pessoa e que Votos começa em zero. Não tente atribuir um valor diretamente a Votos.

8. Etapa 3: criar a classe Eleitor

Objetivo: representar quem tenta votar e guardar no próprio objeto se o voto já foi registrado.

Arquivo: Eleitor.cs

public class Eleitor : Pessoa
{
    private bool jaVotou;

    public bool JaVotou
    {
        get { return jaVotou; }
    }

    public Eleitor(string nome, string cpf)
        : base(nome, cpf)
    {
        jaVotou = false;
    }

    internal void MarcarVoto()
    {
        jaVotou = true;
    }
}
  1. Escreva : Pessoa para herdar Nome e Cpf.
  2. Declare jaVotou como privado e inicialize seu valor como false.
  3. A propriedade JaVotou permite consultar o estado sem alterá-lo diretamente.
  4. O método MarcarVoto muda o estado para true. A urna chamará esse método somente depois de computar o voto.

Limite desta regra: a marcação existe apenas no objeto em memória. Ela impede uma segunda operação com a mesma instância, mas não identifica automaticamente duas instâncias que tenham o mesmo CPF.

9. Etapa 4: criar a classe UrnaEletronica

Objetivo: armazenar os candidatos, aplicar as regras de voto e produzir um resumo sem escrever diretamente no console.

Arquivo: UrnaEletronica.cs

using System;

public class UrnaEletronica
{
    private Candidato?[] candidatos;
    private int totalCadastrados;
    private int votosBrancos;
    private int votosNulos;

    public int VotosBrancos
    {
        get { return votosBrancos; }
    }

    public int VotosNulos
    {
        get { return votosNulos; }
    }

    public UrnaEletronica(int capacidade)
    {
        if (capacidade <= 0)
        {
            throw new ArgumentOutOfRangeException(nameof(capacidade));
        }

        candidatos = new Candidato?[capacidade];
        totalCadastrados = 0;
        votosBrancos = 0;
        votosNulos = 0;
    }

    public bool CadastrarCandidato(Candidato? candidato)
    {
        if (candidato == null)
        {
            return false;
        }

        if (BuscarCandidato(candidato.Numero) != null)
        {
            return false;
        }

        if (totalCadastrados == candidatos.Length)
        {
            return false;
        }

        candidatos[totalCadastrados] = candidato;
        totalCadastrados++;
        return true;
    }

    public Candidato? BuscarCandidato(int numero)
    {
        for (int indice = 0; indice < totalCadastrados; indice++)
        {
          Candidato? candidato = candidatos[indice];
          if (candidato != null && candidato.Numero == numero)
          {
            return candidato;
          }
        }

        return null;
    }

    public bool RegistrarVoto(Eleitor? eleitor, int numero)
    {
        if (eleitor == null || eleitor.JaVotou)
        {
            return false;
        }

        Candidato? candidato = BuscarCandidato(numero);

        if (candidato == null)
        {
            votosNulos++;
        }
        else
        {
            candidato.AdicionarVoto();
        }

        eleitor.MarcarVoto();
        return true;
    }

    public bool RegistrarVotoBranco(Eleitor? eleitor)
    {
        if (eleitor == null || eleitor.JaVotou)
        {
            return false;
        }

        votosBrancos++;
        eleitor.MarcarVoto();
        return true;
    }

    public string ApurarResultados()
    {
        string resultado = "APURAÇÃO DE VOTOS" + Environment.NewLine;
        resultado += "-----------------" + Environment.NewLine;

        for (int indice = 0; indice < totalCadastrados; indice++)
        {
          Candidato? candidato = candidatos[indice];
          if (candidato != null)
          {
            resultado += "Número: " + candidato.Numero;
            resultado += " | Nome: " + candidato.Nome;
            resultado += " | Partido: " + candidato.Partido;
            resultado += " | Votos: " + candidato.Votos;
            resultado += Environment.NewLine;
          }
        }

        resultado += "Votos brancos: " + votosBrancos + Environment.NewLine;
        resultado += "Votos nulos: " + votosNulos;
        return resultado;
    }
}

9.1. Como o array é controlado

  1. O construtor recebe capacidade e cria new Candidato[capacidade].
  2. O array tem posições de 0 até capacidade - 1. Inicialmente, todas estão vazias.
  3. totalCadastrados começa em zero e aponta para a próxima posição livre.
  4. O cadastro só grava na posição indicada depois de verificar candidato nulo, número duplicado e capacidade disponível.
  5. A busca e a apuração percorrem índices menores que totalCadastrados. Elas não percorrem posições vazias.

9.2. Como cada voto é processado

  1. A urna verifica se o eleitor foi informado e se JaVotou é false.
  2. Para voto nominal, a urna busca o número. Se encontrar o candidato, chama AdicionarVoto. Se não encontrar, incrementa votosNulos.
  3. Depois de computar voto válido ou nulo, a urna chama MarcarVoto e retorna true.
  4. Para voto branco, a urna incrementa votosBrancos, marca o eleitor e retorna true.
  5. Se o eleitor for nulo ou já tiver votado, a operação retorna false antes de alterar qualquer contador.

Verificação: cadastre dois candidatos em uma urna de capacidade dois. O terceiro cadastro deve retornar false. Busque um número existente e um inexistente. Confirme que a busca inexistente retorna null.

10. Etapa 5: demonstrar o uso em Program.cs

Objetivo: criar os objetos, chamar as operações e exibir os resultados. O programa não contém os contadores nem percorre o array de candidatos.

Arquivo: Program.cs

using System;

class Program
{
    private static void Main()
    {
        UrnaEletronica urna = new UrnaEletronica(2);

        Candidato candidatoUm = new Candidato("Ana Lima", "CPF-001", 11, "Partido A");
        Candidato candidatoDois = new Candidato("Caio Souza", "CPF-002", 22, "Partido B");
        Candidato candidatoRepetido = new Candidato("Outra Pessoa", "CPF-003", 11, "Partido C");
        Candidato candidatoSemVaga = new Candidato("Bia Reis", "CPF-004", 33, "Partido D");

        Console.WriteLine("Cadastro do candidato 11: " + urna.CadastrarCandidato(candidatoUm));
        Console.WriteLine("Cadastro do candidato 22: " + urna.CadastrarCandidato(candidatoDois));
        Console.WriteLine("Cadastro de número repetido: " + urna.CadastrarCandidato(candidatoRepetido));
        Console.WriteLine("Cadastro sem vaga: " + urna.CadastrarCandidato(candidatoSemVaga));

        Eleitor eleitorUm = new Eleitor("Dani Alves", "CPF-101");
        Eleitor eleitorDois = new Eleitor("Eli Santos", "CPF-102");
        Eleitor eleitorTres = new Eleitor("Fran Costa", "CPF-103");

        Console.WriteLine("Voto no candidato 11: " + urna.RegistrarVoto(eleitorUm, 11));
        Console.WriteLine("Voto branco: " + urna.RegistrarVotoBranco(eleitorDois));
        Console.WriteLine("Voto no número 99: " + urna.RegistrarVoto(eleitorTres, 99));
        Console.WriteLine("Segundo voto do eleitor 1: " + urna.RegistrarVoto(eleitorUm, 22));

        Console.WriteLine();
        Console.WriteLine(urna.ApurarResultados());
    }
}

Dados usados: a urna tem capacidade para dois candidatos. Os textos CPF-001 a CPF-103 são identificadores fictícios; o exercício não verifica CPF.

Resultado das chamadas: os dois primeiros cadastros retornam true; o número repetido e o cadastro sem vaga retornam false. O voto nominal, o voto branco e o número inexistente retornam true, pois foram computados. A segunda tentativa do primeiro eleitor retorna false.

Resultado final esperado: candidato 11 com um voto, candidato 22 com zero votos, um voto branco e um voto nulo.

11. Conferir cada comportamento

  • Cadastro válido: há espaço e o número ainda não existe. Retorno true; o candidato ocupa uma posição e totalCadastrados aumenta.
  • Cadastro recusado: candidato nulo, número repetido ou array cheio. Retorno false; array e quantidade cadastrada não mudam.
  • Voto nominal encontrado: o candidato recebe um voto e o eleitor é marcado. Retorno true.
  • Número não cadastrado: votos nulos aumenta e o eleitor é marcado. Retorno true.
  • Voto branco: votos brancos aumenta e o eleitor é marcado. Retorno true.
  • Eleitor nulo ou já votante: retorno false. Nenhum contador de votos é alterado.

12. Erros comuns e como conferir

  • Percorrer candidatos.Length: isso inclui posições ainda vazias. Use a condição indice < totalCadastrados.
  • Incrementar totalCadastrados antes de gravar: grave o candidato na posição livre e só então incremente o contador.
  • Expor votos com set público: isso permite que outra classe altere a contagem sem registrar um voto. Mantenha o campo privado e a propriedade somente para leitura.
  • Marcar o eleitor antes de validar: a marcação deve ocorrer somente depois que um voto válido, branco ou nulo for computado.
  • Contar número inexistente como voto recusado: neste simulador, o eleitor pode confirmar um número inexistente; esse voto é computado como nulo.
  • Colocar regras no Program.cs: o programa de demonstração chama a urna. Ele não deve procurar candidatos nem incrementar contadores.

13. Atividade de conferência

Execute o programa e confira os resultados esperados. Depois, faça cada alteração separadamente e execute novamente:

  1. Altere a capacidade da urna para 1. Cadastre dois candidatos e confirme que o segundo cadastro retorna false.
  2. Registre um voto para cada candidato. Confirme que o voto do número inexistente é nulo.
  3. Tente registrar dois votos usando a mesma instância de Eleitor. Confirme que somente o primeiro é computado.
  4. Crie duas instâncias de Eleitor com o mesmo CPF e teste uma votação com cada uma. Explique por que ambas são aceitas neste modelo.

Critérios de conclusão

  • As quatro classes do domínio estão em arquivos separados.
  • Candidato e Eleitor herdam de Pessoa e chamam o construtor base.
  • O array não ultrapassa a capacidade e as buscas ignoram posições vazias.
  • Os contadores só mudam quando a operação aceita e computa um voto.
  • Program.cs demonstra o uso das classes sem implementar as regras da urna.

14. Resumo

  • Pessoa reúne os dados comuns usados por Candidato e Eleitor.
  • UrnaEletronica controla o array de candidatos, os cadastros e os votos.
  • totalCadastrados separa as posições ocupadas das posições vazias.
  • O campo privado jaVotou impede nova votação pela mesma instância do eleitor.
  • Program.cs instancia as classes e demonstra suas operações; não contém as regras de negócio.
