Módulo 10

Heranca

Objetivo: reaproveitar código com classe base e classe derivada, reduzindo repetição.

1. Introducao teorica

Heranca permite criar uma classe nova usando atributos e metodos de outra classe.

A classe que fornece os membros e chamada classe base. A nova classe e chamada classe derivada.

2. Conceitos essenciais desta aula

  • Classe base: define membros comuns para reuso.
  • Classe derivada: herda membros da classe base e pode adicionar novos.
  • Reuso: evita duplicar codigo igual em varias classes.

3. Exemplo em C#

Arquivo 1: Pessoa.cs

using System;

public class Pessoa
{
    public string Nome;

    public void Apresentar()
    {
        Console.WriteLine("Nome: " + Nome);
    }
}

Arquivo 2: Aluno.cs

using System;

public class Aluno : Pessoa
{
    public string Turma;

    public void ExibirTurma()
    {
        Console.WriteLine("Turma: " + Turma);
    }
}

Arquivo 3: Funcionario.cs

using System;

public class Funcionario : Pessoa
{
    public string Cargo;

    public void ExibirCargo()
    {
        Console.WriteLine("Cargo: " + Cargo);
    }
}

Arquivo 4: Program.cs

using System;

class Program
{
    static void Main()
    {
        Aluno a = new Aluno();
        a.Nome = "Iara";
        a.Turma = "1A";

        Funcionario f = new Funcionario();
        f.Nome = "Carlos";
        f.Cargo = "Tecnico";

        a.Apresentar();
        a.ExibirTurma();

        f.Apresentar();
        f.ExibirCargo();
    }
}

4. Leitura guiada do exemplo

  1. Pessoa concentra o atributo comum Nome e o metodo Apresentar().
  2. Aluno herda de Pessoa e adiciona Turma.
  3. Funcionario herda de Pessoa e adiciona Cargo.
  4. As duas classes derivadas reutilizam o metodo Apresentar() sem duplicar codigo.

5. Erros comuns nesta etapa

  • Copiar e colar atributos iguais em vez de criar classe base.
  • Usar heranca quando nao ha relacao logica entre as classes.
  • Criar classe base com muitos detalhes que so uma classe usa.

  2. Exercicio 2: crie a classe derivada Carro com atributo Portas.

  3. Exercicio 3: explique por que heranca pode reduzir repeticao.

    Ver resposta

    Porque membros comuns ficam na classe base e sao reutilizados pelas classes derivadas.

  4. Exercicio 4: crie duas classes filhas de Veiculo e mostre atributos comuns e especificos.

    Ver resposta

7. Resumo da aula

Heranca organiza reuso de codigo entre classes relacionadas.

Com classe base e derivada, o sistema fica mais limpo e mais facil de manter.

8. Atividade guiada

Passo 1: crie classe base Pessoa com Nome e ExibirNome().

Passo 2: crie classe Professor herdando de Pessoa com atributo Disciplina.

Passo 3: crie classe Aluno herdando de Pessoa com atributo Turma.

Passo 4: instancie os objetos e mostre dados comuns e especificos.
