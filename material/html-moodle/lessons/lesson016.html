Aula 16 - Conexao com banco em C#

Objetivo: abrir conexao, executar comando e fechar conexao.

Conceitos desta aula

  • Connection string
  • SqlConnection
  • SqlCommand

Definicoes

Connection string identifica o banco. SqlConnection abre conexao. SqlCommand executa comandos SQL.

Explicacao curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

using var conexao = new SqlConnection(connectionString);
conexao.Open();
using var comando = new SqlCommand("SELECT 1", conexao);
var resultado = comando.ExecuteScalar();

Resumo

Conexao deve ser aberta e fechada com controle.

Atividade

Escreva o fluxo: abrir conexao, executar consulta, fechar conexao.
