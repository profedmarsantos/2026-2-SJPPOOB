Conexao com Banco em C#

Objetivo: executar o fluxo de conexao, comando e fechamento de recurso com seguranca.

Introducao teorica

Para conversar com o banco em C#, o programa precisa de uma string de conexao e classes de acesso.

O fluxo basico e: abrir conexao, executar comando, ler resultado e fechar conexao.

Conceitos essenciais desta aula

  • Connection string: endereco e parametros de acesso ao banco.
  • SqlConnection: objeto responsavel por abrir e fechar conexao.
  • SqlCommand: objeto que executa SQL.
  • using: garante liberacao automatica de recurso.

Exemplo em C#

using System;
using System.Data.SqlClient;

class Program
{
    static void Main()
    {
        string connectionString = "Server=SERVIDOR;Database=Escola;Trusted_Connection=True;";

        using (SqlConnection conexao = new SqlConnection(connectionString))
        {
            conexao.Open();

            string sql = "SELECT COUNT(*) FROM Alunos";
            using (SqlCommand comando = new SqlCommand(sql, conexao))
            {
                int total = (int)comando.ExecuteScalar();
                Console.WriteLine("Total de alunos: " + total);
            }
        }
    }
}

Leitura guiada do exemplo

  1. A string de conexao identifica servidor e banco.
  2. SqlConnection abre a sessao com Open().
  3. SqlCommand executa o SQL definido.
  4. ExecuteScalar() retorna um unico valor, no caso a contagem.
  5. Os blocos using fecham os recursos automaticamente.

Erros comuns nesta etapa

  • Esquecer de abrir conexao antes de executar comando.
  • Manter conexao aberta sem necessidade.
  • Nao tratar erro de conexao em ambiente real.

Resumo da aula

Conexao com banco exige fluxo tecnico simples e rigoroso.

Com using, SqlConnection e SqlCommand, o codigo fica mais seguro para evoluir.

Passo 2: monte um codigo com SqlConnection e SqlCommand.
