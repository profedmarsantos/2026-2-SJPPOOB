Módulo 16 - Conexão com Banco em C#

Objetivo: Abrir Conexão, Executar Comando e Fechar Conexão.

Conceitos Desta Aula

  • Connection string
  • SqlConnection
  • SqlCommand

Definições

Connection string identifica o banco. SqlConnection abre Conexão. SqlCommand executa comandos SQL.

Explicação Curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo Curto

using var Conexão = new SqlConnection(connectionString);
Conexão.Open();
using var comando = new SqlCommand("SELECT 1", Conexão);
var resultado = comando.ExecuteScalar();

Resumo

Conexão deve ser aberta e fechada com controle.

Atividade

Escreva o fluxo: abrir Conexão, executar consulta, fechar Conexão.
