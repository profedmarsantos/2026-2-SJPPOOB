Módulo 18 - Geração de Relatórios

Objetivo: Organizar Dados Consultados em Saida Clara.

Conceitos Desta Aula

  • Relatório
  • Consulta
  • Filtro
  • Ordenação

Definições

Relatório é uma apresentação organizada dos dados para leitura e decisão.

Explicação Curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo Curto

Console.WriteLine("RELATORIO DE ALUNOS");
Console.WriteLine("Nome | Turma");

Resumo

Relatorio depende de dados corretos e formato claro.

Atividade

Monte um layout textual de relatorio com cabeçalho e duas colunas.
