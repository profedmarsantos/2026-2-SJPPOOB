Módulo 18

Geracao de Relatorios

Objetivo: apresentar dados consultados em formato claro, com filtro e ordenacao.

Introducao teorica

Relatorio transforma dados do banco em informacao util para leitura e decisao.

Um bom relatorio precisa de consulta correta, organizacao visual e criterio de ordenacao.

Conceitos essenciais desta aula

  • Consulta: SQL que recupera os dados necessarios.
  • Filtro: condicao para exibir somente parte dos registros.
  • Ordenacao: definicao da sequencia de exibicao.
  • Layout: estrutura de cabecalho, colunas e totalizadores.

Exemplo em C#

using System;
using System.Data.SqlClient;

class Program
{
    static void Main()
    {
        string sql = "SELECT Nome, Turma, NotaFinal FROM Alunos ORDER BY Nome";

        Console.WriteLine("RELATORIO DE ALUNOS");
        Console.WriteLine("Nome                 | Turma | Nota");
        Console.WriteLine("--------------------------------------");

        using (SqlCommand comando = new SqlCommand(sql, conexao))
        using (SqlDataReader leitor = comando.ExecuteReader())
        {
            while (leitor.Read())
            {
                string nome = leitor.GetString(0);
                string turma = leitor.GetString(1);
                decimal nota = leitor.GetDecimal(2);

                Console.WriteLine($"{nome,-20} | {turma,-5} | {nota}");
            }
        }
    }
}

Leitura guiada do exemplo

  1. A consulta busca nome, turma e nota final.
  2. ORDER BY Nome organiza o resultado em ordem alfabetica.
  3. Cabecalho textual melhora a leitura no console.
  4. O loop do SqlDataReader imprime linha por linha.

Exercicios de fixacao

  1. Exercicio 1: escreva SQL para listar produtos ordenados por preco crescente.

    Ver resposta 
    SELECT Nome, Preco FROM Produtos ORDER BY Preco ASC;

  2. Exercicio 2: adicione filtro para mostrar apenas alunos da turma 1A.

    Ver resposta 
    SELECT Nome, Turma FROM Alunos WHERE Turma = '1A';

  3. Exercicio 3: explique por que cabecalho e separador ajudam no relatorio.

    Ver resposta

    Porque deixam o formato previsivel e facilitam leitura rapida das colunas.

  4. Exercicio 4: monte um relatorio textual com duas colunas e total no final.

    Ver resposta

    Use Console.WriteLine para cabecalho, loop para linhas e uma linha final com totalizador.

Resumo da aula

Relatorio combina consulta correta com apresentacao clara.

Filtro, ordenacao e layout bem definido tornam os dados mais uteis para decisao.

Atividade guiada

Passo 1: escolha uma tabela e tres colunas para relatorio.

Passo 2: escreva SQL com filtro e ordenacao.

Passo 3: desenhe o cabecalho e o formato de exibicao no console.

Passo 4: inclua uma linha final com total de registros exibidos.
