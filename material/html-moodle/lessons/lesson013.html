Módulo 13

Interfaces

Objetivo: definir contratos de implementacao para padronizar comportamentos entre classes diferentes.

Introducao teorica

Interface define um contrato: quais metodos uma classe deve implementar.

Ela nao guarda estado. Ela padroniza comportamento.

Conceitos essenciais desta aula

  • Interface: contrato de membros sem implementacao concreta.
  • Implementacao: classe que cumpre todos os metodos exigidos pelo contrato.
  • Padronizacao: classes diferentes respondem ao mesmo conjunto de operacoes.

Exemplo em C#

Arquivo 1: IRelatorio.cs

using System;

public interface IRelatorio
{
    void Gerar();
}

Arquivo 2: RelatorioAluno.cs

using System;

public class RelatorioAluno : IRelatorio
{
    public void Gerar()
    {
        Console.WriteLine("Relatorio de aluno gerado");
    }
}

Arquivo 3: RelatorioFinanceiro.cs

using System;

public class RelatorioFinanceiro : IRelatorio
{
    public void Gerar()
    {
        Console.WriteLine("Relatorio financeiro gerado");
    }
}

Arquivo 4: Program.cs

using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        List<IRelatorio> relatorios = new List<IRelatorio>
        {
            new RelatorioAluno(),
            new RelatorioFinanceiro()
        };

        foreach (IRelatorio relatorio in relatorios)
        {
            relatorio.Gerar();
        }
    }
}

Leitura guiada do exemplo

  1. A interface IRelatorio exige o metodo Gerar().
  2. Cada classe implementa o mesmo metodo com resultado proprio.
  3. A lista usa o tipo da interface, nao o tipo concreto das classes.
  4. O codigo consumidor chama Gerar() de forma padronizada.

Exercicios de fixacao

  1. Exercicio 1: crie a interface IExportavel com metodo Exportar().

    Ver resposta 
    interface IExportavel
{
    void Exportar();
}

  2. Exercicio 2: implemente ExportadorCsv e ExportadorPdf.

    Ver resposta

    As duas classes devem implementar Exportar() com mensagens diferentes.

  3. Exercicio 3: explique a diferenca entre heranca de classe e implementacao de interface.

    Ver resposta

    Heranca reaproveita codigo de uma classe base. Interface define apenas o contrato que a classe deve cumprir.

  4. Exercicio 4: crie uma lista de IExportavel e execute Exportar() em cada item.

    Ver resposta

    Use List<IExportavel> e foreach para chamar o metodo padronizado.

Resumo da aula

Interfaces criam contratos claros entre partes do sistema.

Elas aumentam padronizacao e facilitam troca de implementacoes.

Passo 2: implemente as classes EmailNotificador e SmsNotificador.

Passo 3: use uma lista de INotificador para executar todos os envios.
