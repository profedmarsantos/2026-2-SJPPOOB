Aula 13 - Interfaces

Objetivo: definir contratos de implementacao.

Conceitos desta aula

  • Interface
  • Contrato
  • Implementacao

Definicoes

Interface define metodos que a classe deve implementar.

Explicacao curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

interface IRelatorio
{
    void Gerar();
}

class RelatorioAluno : IRelatorio
{
    public void Gerar() { Console.WriteLine("Relatorio"); }
}

Resumo

Interfaces padronizam comportamento entre classes diferentes.

Atividade

Crie uma interface IExportavel com metodo Exportar().
