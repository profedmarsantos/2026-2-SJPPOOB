Aula 19 - distribuição do aplicativo

Objetivo: preparar o sistema para uso em outros computadores.

Conceitos desta aula

  • Build
  • Publicação
  • Arquivo executável

Definições

Distribuir e entregar o sistema pronto para execucao em ambiente de uso.

Explicação curta

Aplicar este conceito com exemplos pequenos melhora a leitura e prepara a turma para programas maiores.

Exemplo curto

dotnet publish -c Release

Resumo

Publicação correta reduz erros no ambiente final.

Atividade

Descreva quais arquivos são necessarios para entregar a aplicacao.
